读了 `research/verdicts/DEP-001.json`。我的第五次 review 结论：

1. **红线清了，但 loop 的话术不合格。**  
   `holder_pct` 确认是 PIT 违规因子，且 DEP-001 唯一改动就是剔除它，所以“硬红线已清除”这个判断成立。  
   但“clean确认 = holder 对 book Sharpe 无实质影响、真实基线维持约 1.31”不成立。CI 含 0 只能说明**无法统计确认剔除 holder 导致 Sharpe 下降**，不能反过来证明“无材料影响”。尤其 CI 是 `[-1.246, +0.312]`，里面包含很大的负影响；这不是等价性检验。更诚实的标签应是：  
   **PIT 红线已清除；剔除后结果与 WFE-001 统计不可区分，但点估计明显偏低，book Sharpe 估计噪声很大。**

2. **同意你的质疑：这是 1.31 不该被当精确数字宣称的强证据。**  
   `holder_pct` 的 r20 gain 只有 `0.005%`、全期 IC 只从 `0.0979` 到 `0.0952`，信号层几乎没动；但组合 Sharpe 从 `1.31` 到 `0.84`，说明 book 层对边际排序、top picks、约束、再平衡路径非常敏感。  
   这更像是 **20-cohort OOS book 的采样噪声 / 路径依赖 / top-bucket 边际不稳**，而不是 holder 本身提供了真实 alpha。  
   但也不能完全排除结构性问题：随机森林重训后 split 路径变化、边际股票替换、行业 cap4 约束、双轨 pick 交互，都可能把很小的特征扰动放大到组合层。建议把它解释为“组合层稳定性不足”，不要解释成“holder 不重要所以 1.31 仍可信”。

3. **PIT-clean r20 可以作为 paper-trade 变体，不应作为已验证可部署收益版本。**  
   可部署期望不应写 `1.31`，也不应机械写 `0.84`。最诚实表述是：  
   **PIT-clean 后历史 OOS 仍为正，净 Sharpe 点估计约 0.84，且相对基准仍有优势；但可实现 Sharpe 应按宽带处理，大致只能宣称“正期望但不精确”，不能宣称 1.31 级别稳定 alpha。**

我会给最终裁决改成：

> DEP-001 清除了唯一确认硬前视因子。剔除 holder 后 r20 仍为正且跑赢主要基准，但 Sharpe 点估计从 1.31 降至 0.84，配对 bootstrap 未能排除噪声解释，也未能证明性能不受材料影响。该结果支持进入冻结 + 前向 paper-trade，而不是支持把 1.31 作为生产预期。

下一步我认为就是**冻结 PIT-clean 版本做前向 paper-trade**，同时补三个只读稳定性检验最有价值：

- 多 seed / 重训稳定性：看剔单个低重要度特征是否普遍引起类似 Sharpe 摆动。
- pick overlap / rank turnover：定位 0.46 Sharpe 摆动来自少数边际票还是全局排序重排。
- cohort jackknife / leave-one-period-out：确认 0.84 与 1.31 是否被少数 cohort 主导。

短结论：**红线清了；loop 的“clean确认”应降级；部署预期要下修为“正但宽带”，前向 paper-trade 是正确下一步。**
