## DEP-001 — holder_pct 剔除 (2026-06-14, 硬红线状态更新)

**holder_pct 泄漏确认 + 剔除**: `compute_holder_pct_at` 按 `end_date<=target_date` 选数、未取 ann_date = 真前视(Q1 end_date 0331 在 ~0430 公告前即用)。但 r20 gain 仅 **0.005%**(排 118/236, 2 split)= 噪声级。**剔除处理**(零 ann_date 工程)。

**剔后 PIT-clean r20 (234 特征, 余口径同 WFE-001 apples-to-apples)**:
- book 净Sharpe **+0.84** / 年化 +19.9% / maxDD -26.8%; vs 含 holder 1.31 → ΔSharpe **-0.464**。

**红线状态 = 清除 (但带噪声 nuance, 比 loop 的 "clean确认" 更诚实)**:
- 泄漏因子已剔, IC 证明无真信号丢失 → 红线该清的清了, PIT-clean r20 = 可部署变体。
- ⚠ **但一个 0.005% 重要度因子剔除即晃点估计 0.46(P变差89%)= 最强证据: 20-cohort book Sharpe 被噪声主导, 1.31 不该当精确数字**(呼应 FIN-001 CI[0.11,2.60] + codex#4 功率不足)。

### codex 第五次 review (2026-06-15) — "clean确认"降级 + 部署预期下修

codex 独立审 DEP-001, 确认我的自审并精化:
- **"CI 含 0" 不是等价性检验**: 只说明"无法统计确认剔 holder 导致 Sharpe 下降", **不能反证"无材料影响"**(absence of evidence ≠ evidence of absence)。loop 的 "clean确认" **应降级**为: "PIT 红线已清除; 剔除后与 WFE-001 统计不可区分, 但点估计明显偏低, book Sharpe 估计噪声很大。"
- **0.46 摆动**: 主因 20-cohort 采样噪声 + **组合层稳定性不足**(边际排序/top picks/行业cap4/双轨交互把 0.005% 特征扰动放大到组合层); 非 holder 提供真 alpha。**解释为"组合层稳定性不足", 不可解释为"holder 不重要所以 1.31 仍可信"。**
- **部署预期**: 不写 1.31, 也不机械写 0.84。最诚实 = **"PIT-clean 历史 OOS 仍为正, 净 Sharpe 点估计 ~0.84, 跑赢基准; 但可实现 Sharpe 按宽带处理, 只能宣称'正期望但不精确', 不能宣称 1.31 级稳定 alpha。"**

**codex 最终裁决**: DEP-001 清除了唯一确认硬前视因子; 剔 holder 后 r20 仍正且跑赢基准, 但点估计 1.31→0.84, 配对 bootstrap 未能排除噪声、也未能证明无材料影响。**支持进入冻结 + 前向 paper-trade, 不支持把 1.31 作生产预期。**

**codex 建议的 3 个只读稳定性诊断(定位 0.46 摆动来源)**:
1. 多 seed/重训稳定性: 剔任一低重要度特征是否普遍引起类似 Sharpe 摆动;
2. pick overlap/rank turnover: 0.46 来自少数边际票还是全局重排;
3. cohort jackknife/留一期: 0.84 vs 1.31 是否被少数 cohort 主导。

### DIAG-001/002 (2026-06-15) — 0.46 摆动来源定位 + 两个部署 caveat

codex#5 建议的只读诊断, 复用缓存不重训:
- **DIAG-001 票层 = 全局重排**: WFE-001 vs DEP-001 持仓 Jaccard 仅 0.33, 每 cohort 替换 106% 持仓, 收益差跨 24 只 swing 票铺开(前3只仅 54%) → 剔 1 个 0.005% 因子**重排整批 basket**, top-N 选股对小扰动整体敏感(非个别票)。
- **DIAG-002 cohort 层 = 少数 cohort 主导**: 配对 LOO, 删 cohort #14('20251201','20251226')吃 gap 42%, 有效仅 ~5.5 cohort 拉开两臂 → 0.46 gap 由少数 20d 路径驱动 = **短样本噪声非信息损失**。

**两个部署 caveat (写入部署须知)**:
1. 🟡 **选股不稳/集中风险**: top-N 对小模型扰动重排 ~106%, 真钱时确切 basket 在近平局候选间**部分任意** → 部署前建议**增 N / 降集中**稳健化(strategy 层, 不动冻结的 V12.31 选股逻辑, 作 sizing/组合层改进)。
2. 🟡 **短样本噪声**: 1.31/0.84 gap 几 cohort 主导 → **幅度只能靠前向 paper-trade 定**, 不锚任一点估计。

**这两条不阻止部署, 但应纳入真钱前的稳健性预期**: 实盘可能复现一个"正期望、宽带、basket 部分任意"的策略, 而非一个稳定的 1.31 alpha 机器。
