**关键证据(0508→0603 同窗口)**:

## 4. Part III — 动量 Regime 错配假设与因果尸检 (RG-001 / RG-002)

**假设**:v3c 是均值回归策略,在动量延续 regime 被血洗;一个因果动量-regime 检测器 + 叠加层
(强动量态抑制回调)应能改善。

### RG-001 因果动量-regime 检测器(`research/rg001_regime_detector.py`)
- 核心信号 = **动量持续性价差**:t 日按过去 [t−40,t−20] 的 20d 动量横截面分 10 档,量 [t−20,t]
  已实现收益的 D9−D0 价差(两窗连续全过去,零前视)+ 平滑 + 宽度 + 指数动量。
- **因果性自检 `abs_diff = 0.0`**(抹未来价格重算完全一致);ST 源头排除。
- 分布:momentum 29% / mixed 16% / reversal 55%。
- **独立印证审计**:202605 判 momentum 83% spread +8.87pp;**202606(审计血洗窗)momentum 100% +13.39pp**。
- 产出:`research/features/regime_timeline.parquet`(825 日)。裁决 `built`。

### RG-002 v3c regime 分层尸检(`research/rg002_regime_autopsy.py`)— **假设被推翻**
- 纯因果尸检(805 日,regime 来自 RG-001 causal,fwd20 仅作测量非特征 → 无 lookahead):
  条件于因果动量 regime,**v3c 低动量/回调档前向 α = +0.378pp 显著为正**(t=4.056, p=5e−05),
  反转月 +0.250pp。
- **关键机理**:因果动量 regime 平均**之后跟随均值回归**(前向 D9−D0 = **−1.77pp < 0**)
  → 回调买入在动量态**反被奖励**。
- **审计"动量月血洗"未泛化**:全样本仅 202303(D9−D0 +8.2)/ 202602(+3.3)两个极端月真血洗 =
  **尾部 episode,非系统 regime 效应**。
- 裁决 `hypothesis_rejected` → 据事前注册 precondition,RG-003/004/005 自动 skip。

**关键概念区分**(本研究最重要的方法论洞察之一):

> **"因果动量态(已在趋势)" ≠ "前向动量延续(还会继续涨)"**。
> 二者在决策时刻**负相关**(因果动量后平均反转),**无法因果区分**。
> 实盘血洗是 forward 动量罕见延续的尾部 episode,**不是一个能在决策时刻识别再 gate 掉的系统 regime**。

**诚实限制**:实盘血洗窗 0508–0603 的前向数据未到(尸检窗止 0506),该具体 episode 测不到;
2026 动量日 v3c α 已转**弱负(−0.094pp)**,值得 6 月数据到位后复检。

## 5. Part IV — 四个修复实验与元结论

承 RG-002,把"修复"逐一严格检验。所有实验:apples-to-apples(两臂唯一差异 = 被测干预)、
19 月 walk-forward、事前注册冻结 gate、按 regime 分层、复用 t005 缓存模型免重训、不碰生产文件。

### 5.1 止损 / 尾risk 叠加(`research/rg_stoploss.py`)— REJECT (反指)
- −12% 收盘止损 vs 全程持有:全期 Δ **−0.54pp**,**动量月 Δ −1.00pp(伤最重)**,
  最差月 −3.14→**−3.77**,灾难月 **2→4(凭空造 2 个)**。所有止损档都亏(−8% 最惨)。
- **机理**:v3c 买回调,触发止损的"继续跌"正是它**期望反弹**的条件 → **止损系统性卖在底部,与 edge 反向**。

### 5.2 健康回调 vs 破位飞刀(`research/rg_trendquality.py`)— REJECT (非反指)
- 池构造前加 `close ≥ MA60`(健康趋势)过滤:全期 Δ **−0.07pp(近中性,不反指)**,
  灾难月 2→2 不增(过 2/4 gate);但动量月 Δ 仅 +0.006、最差月未改善 → REJECT。
- **关键亮点**:**202602(窗内唯一极端动量月,最像实盘血洗代理)base −2.27 → filt −1.81,Δ +0.46**
  真帮上,只是被其它动量月摊平。

### 5.3 元结论(`[[project_three_rejects_meanreversion_meta_0603]]`)

把四个实验(含 Part I 的动态窗口)连起来:

| 实验 | 干预侧 | 结果 |
|---|---|---|
| 动态窗口 | 排序 | REJECT(已吃干净) |
| 动量 overlay | 择时 | REJECT(反指) |
| 止损 | 出场 | REJECT(反指) |
| 健康回调过滤 | **选择(入场)** | REJECT,**非反指 + 202602 +0.46** |

> **出场/择时/排序侧的工具全部与均值回归 edge 反向**(它们都在策略期望赢时动作);
> **唯一不反指的是入场选择侧**,且在关键动量月有效。**真正的杠杆在"买哪些回调",不在"何时砍/关"。**

## 5b. Part V — 异类特征:梅花易数起卦(2026-06-04 追加)

**动机(用户提议)**:把梅花易数起卦的卦象作为确定性 categorical 特征,检验其对起涨点(+20)的预测力。
**正确看待方式**:梅花易数 = 一个确定性的"数字→卦象"变换 = 一种 categorical 特征编码器;
是否有信号由数据裁决,不靠人工断语。**先验 = 噪声**(组合卦动态部分≈日历+价格末位,静态卦≈股票ID)。

- **编码器**(`research/meihua_encoder.py`,梅花核心 vendored from `ds-oracle-cli/app/engine/meihua.py`):
  `(ts_code, date, close)` → 组合卦 `mh_*`(本/互/变卦 id + 上下卦 + 动爻 + 体用五行 + 体用关系5类 + 阳爻数)
  + 纯代码静态卦 `mhs_*`。确定性自检=True,零泄漏,体用5类 18–22% 不退化,64 卦全覆盖。
- **MH-001**:全历史 5.3M 行特征落盘(`research/features/meihua_features.parquet`),ST 源头排除。
- **MH-002 Phase-1 廉价筛查 → `no_residual_signal`(REJECT)**:**没偷懒做原始 IC**,而是给卦象公平机会:
  ① OOF target encoding(月度扩张窗 gap=2 月,零泄漏)给名义卦象 id 公平编码;
  ② 正确消融:先用"公历月×板块"残差化 r20,再看梅花对残差的独立 IC。
  - **所有动态 `mh_*` 残差 |IC| ≤ 0.0011**(≪0.01 floor);最强 `mh_yang_count` IC=−0.0011, t=−2.15
    (t 仅因 1012 日样本过线,经济上零)。**朴素对照(月×板块)本身 OOF-IC=+0.0073 = 世俗来源比卦象强 7 倍**。
  - 静态 `mhs_*` IC 较大(−0.018)但扣板块后**反增** → **= 卦象版股票 ID 的个股固定效应,非占卜**。
  - 关键口径:横截面 IC 天然差掉当日全市场常数 ⇒ 纯日历季节性进不了 IC;卦象唯一"信号"是月×板块交互的世俗效应。

**意义**:**SIGN-R12(奇异/玄学特征必须存活朴素消融)首次实战就拦下一个会自欺的特征**——若只看原始 IC,
静态卦的 −0.018 会被误读为"卦象有效",消融一眼看穿那只是股票 ID 固定效应。
**给了卦象 OOF 公平机会、仍是零**,比简单否定更具说服力。
(`[[project_meihua_feature_reject_0604]]`)

## 6. 方法论贡献(论文可用)

本研究的价值**主要在方法论与负结果**,而非一个新的盈利信号:

1. **反过拟合脚手架(anti-overfitting harness)**:ralph 自治循环 + **事前注册冻结 gate**
   (SIGN-R01,循环内不可改阈值)+ **负结果=合法完成**(SIGN-R02,禁止同段 OOS 重调)+
   **中间指标≠落地**(SIGN-R03,只认 walk-forward α)+ **前视泄漏前置闸**(SIGN-R04)+
   **按 regime 分层强制**(SIGN-R11)+ **奇异特征朴素消融闸**(SIGN-R12,扣月历+板块后须存活)。
   **9 次连续 REJECT(含首个正交因子);新教训:18月级"不塌"IC不足以立论,必须≥40月功率检验(基本面成长 18月+0.033 在47月塌为 t=1.08);8 连否的元观察:凡"价格行为再编码"全归约为 V12.31 已捕获的标准 TA → V12.31 是价量信息强局部最优,增量应找正交信息(基本面/另类/微结构),非又一种价量编码。**
2. **横截面分位审计法**:把 picks 前向收益放进全市场排序,**一刀切开 beta 拖累 vs 选股 α**——
   比"vs 单一基准"更抗 beta 污染。
3. **因果 regime 检测器 + 自检**:`abs_diff=0` 抹未来重算验证因果性;区分**因果动量态 vs 前向动量延续**
   (二者负相关、不可因果区分)——这是一个可推广的概念警示。
4. **apples-to-apples 共模相消**:两臂唯一差异=被测干预,使绝对 α 中的共模 lookahead 在 Δ 中相消,
   gate 只看相对量(SIGN-R03)。

### ★ 实验 13 的精妙案例 (本研究最有价值的一条)

龙虎榜「席位印记」(跟高战绩 `exalter` 席位) 是**整轮唯一扛过消融的真信号**, 三次独立确证:
- SEAT-002 横截面残差 IC = **+0.0547 t=8.58 全regime** (扣[动量+市场]仅小幅衰减, 非换皮);
- SL-003 席位技能净增量 Arm_A(席位排序) − Arm_B(动量排序) = **+1.020pp/月 t=4.43 正月75.6%**。

**但三个市场结构性障碍使它不可作 long-only 独立策略落地** (`[[project_seat_footprint_real_signal_wrong_vehicle_0606]]`):
1. **相对信号活在输家池**: 龙虎榜净买入股 universe 本身相对市场净输 (r5 均值回归, 毛α −1.7pp) → 席位只让你"最不差"非"赚钱", long-only 净α −2.0pp t=−6.2。
2. **微容量**: binding 容量中位 ~0.05亿元。
3. **需做空兑现相对价差, 但 A股做空受限** (融券难/贵/小盘不可空, 龙虎榜多小盘)。
- **教训: "信号真" ≠ "能赚钱"。** 一个统计显著、扛消融、全regime的正交信号, 仍可能因 universe 绝对方向 + 容量 + 做空约束 而无法 monetize。这是比"又一个REJECT"深一层的发现。
