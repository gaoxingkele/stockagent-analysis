## 0. 一句话目标

用「K 线相对位置」的**多尺度软符号关系张量**替代/补充原始 K 线作输入,经 CNN+时序编码后与标量因子融合,
输出**截面启动子分数**(承接生产下游:选高分潜力股 / 高分启动子),
并以 **walk-forward 组合 α + 标准 TA 消融 + 单月 outlier 检验** 严格证伪。

**核心待答**:CNN 学到的「跨格/跨阶非线性形态交互」,能否在扣除标准 TA 标量版后仍带可交易增量?

## 1. 输入表示:关系张量 v2

### 1.1 单元格编码（核心改进:软符号 + 波动/阶归一化)

价格集 P = {O, C, H, L}(+ 量 V 单独处理,见 1.3)。锚点 K_p 对其前第 d 根 K_{p-d}:

```
ℓ_{ij}^(d) = ln( K_p.i / K_{p-d}.j )                 # 对数比, i,j ∈ {O,C,H,L}
z_{ij}^(d) = ℓ_{ij}^(d) / ( σ_p · √d )               # 波动归一(跨股可比) + √d 阶归一(跨阶可比)
v_{ij}^(d) = tanh( z_{ij}^(d) / κ )                  # 软符号 ∈ (−1,+1): 大缺口→±1, 小波动→≈线性
```
- `σ_p` = 该股近 20 日**日收益**标准差(决策时刻已知,causal)。
- `√d` = 扩散修正(d 日对比方差 ∝ d)。
- `κ` = 软硬旋钮(死区软度);**±0.5% 死区自动涌现**(小 z → tanh≈0),无需武断硬阈值。
- κ→0 退化为用户原始硬符号 ±1;κ≈1 时 1σ→0.76、3σ→0.995。**默认 κ=1**。

→ 单矩阵 `4×4` 连续值。可选**双通道**:通道 A=硬符号 sign(z)(离散形态:缺口/吞没本就是类别),
通道 B=连续 v。**首版用连续单通道**(简单且够),双通道留作消融变体。

### 1.2 阶 / 锚点 / 窗口（沿用用户最终口径）

- **每锚点** K_p → 对前 5 根的 5 个矩阵 → `5×4×4` 张量(深度=5)。
- **样本窗口** 有 N+5 根 K 线 → N 个锚点(K0, K(-1), … K(-(N-1)))滑动 → **`N × 5 × 4 × 4`** 序列张量。
- 时间轴**正序**(最老锚点 → K0)喂模型。默认 **N=20**(窗口 25 根)。

### 1.3 补强通道（梅花教训:少了这些会瘸腿)

1. **量(Volume)** — 起涨点 = 形态 + 放量。每锚点每阶加量比:
   `vol_p^(d) = tanh( ln(V_p/V_{p-d}) / (σ^V_p · √d) )` → 每锚点 `5×1` 量关系向量(σ^V=量的对数波动)。
2. **自身形态** S_p（锚点 K 自身,lag-free): 实体 (C−O)/(H−L)、上影 (H−max(O,C))/(H−L)、
   下影 (min(O,C)−L)/(H−L)、归一振幅 (H−L)/(σ_p·C)、跳空 (O−C_{p-1})/(σ_p·C_{p-1})。→ 每锚点 `5` 标量。

**每锚点完整输入** = 价格关系 `5×4×4` + 量关系 `5` + 自身形态 `5`。

### 1.4 因果 / 泄漏（硬约束)

- 全部仅用 K0 及之前数据 → causal,零泄漏。
- 未来侧 K1/K2 的同款矩阵**只能进 label**,绝不进特征(verify.py 黑名单照查)。
- ST 源头排除(SIGN-R06)。

## 2. 模型架构

```
锚点输入 (5×4×4 价 + 5 量 + 5 形态)
   └─ 小 CNN/MLP(per-anchor encoder) ──► 锚点 embedding (32-d)
N 个锚点 embedding
   └─ TCN / 轻 Transformer(沿 N 时间轴) ──► 序列 embedding (64-d) ──┐
标量因子块 (quant_score / 选定 153 因子 / 量价) ───────────────────────┤── concat ──► MLP head ──► 启动子 score
                                                                      ┘
```
- per-anchor 80+10 维,CNN 给「跨阶×跨价位」局部性归纳偏置;MLP 是合理 baseline。
- **架构对冲(重要,见 §6 风险)**:本项目历史上 GBDT 在月度 walk-forward 低数据régime下常胜 NN。
  故并行准备 **两条 head**:(a) 纯 NN end-to-end;(b) **CNN/TCN 作特征提取器 → 冻结 embedding 喂 GBDT**。
  以 walk-forward α 决定用哪条,不预设 NN 赢。

## 3. 标签 / 下游（与生产 apples-to-apples）

**直接复用生产 v3c pump 标签**(不另造,保证可比):
- 前向 5 日:up = `max_gain≥10% & max_dd≥−5%`,3 分类(up/down/neutral),`past_r5≤+8%` 时序约束。
- 输出 `P_up`(或 ratio = P_up/(P_down+ε))= **启动子分数**。
- 下游评估 = 生产同款:截面排序 → V7c 池/top-N → **walk-forward 组合 α**(非 IC,SIGN-R03)。
- 备选目标:r20 截面排序(选潜力股)。两者都跑,主目标 = pump(启动子)。

## 4. 消融实验设计（核心:防「标准 TA 换皮」)

四臂,apples-to-apples(同标签/同池/同回测,唯一差异=特征与模型):

| 臂 | 特征 | 模型 | 作用 |
|---|---|---|---|
| **A0 baseline** | 标准标量 TA(多尺度动量 + ATR/range + 量比 + 缺口)+ 生产因子 | GBDT | 强 baseline,= 张量编码内容的标量版 |
| **A1 张量-only** | 关系张量 v2 | CNN/TCN | 看张量单独能力 |
| **A2 融合** | 张量 + A0 标量 | CNN+GBDT/NN | **主张量假设** |
| **A3 张量替代** | 张量替代 K 线(去 A0 的 TA,保留基本面)| CNN | 看「替代」可行性(预期最弱) |

**决定性对照** = A2 vs A0:张量在 **A0 已含标量 TA** 之上,还能不能挤出增量。
若 A2 ≈ A0,则张量 = 标准 TA 换皮(梅花教训重演)。

## 5. 事前注册冻结 gate（启动时锁死,SIGN-R01）

**Phase-1 廉价筛查**(先跑,省算力):
- A2 模型 OOF 预测对 r20/pump 的残差(扣 A0 标量 TA + 月×板块)|rank-IC| ≥ 0.01 且 |t| ≥ 3 → 继续 Phase-2;否则廉价 REJECT。

**Phase-2 walk-forward 决策 gate**(19 月 202410–202604,协议同 t005):
- `Δα(A2 − A0) ≥ +0.30pp/月`,**且**
- Sharpe / 最差月不低于 A0,**且**
- **单月 outlier 检验**:剔除任一单月后 Δα 仍 > 0(防伪增益,轨迹梅花教训),**且**
- 按 regime 分层无伤(SIGN-R11:动量/反转月均不显著恶化),**且**
- 增量在 A0 已含标准 TA 标量版后仍存在(SIGN-R12 升级:扣多尺度动量+range+量+缺口)。
- 全满足 → PASS(进 opt-in 落地评估);否则 REJECT(文档化,生产线不动)。

## 6. 诚实先验 / 风险 / 算力

- **先验**:中性偏保守。方向**不是结构性必死**(有意义的价格几何,非梅花数论),但大头预测内容 = 多尺度动量+波动+量+缺口;真增量只在 CNN 的**非线性形态交互**,小而需验证。
- **风险 1（最大）**:NN 在月度 walk-forward 低数据régime易过拟合/不稳;历史上 GBDT 常胜
  (见记忆 project_v12_agentic_paper_pathway_0530:NN/对比学习曾被否,LGBM 在随机样本最优)。→ §2 架构对冲(GBDT 吃 embedding)。
- **风险 2**:张量与标量 TA 高共线 → A2≈A0(换皮)。→ §4 A2-vs-A0 主对照直击。
- **风险 3**:窗口×锚点×通道维度大,因果滚动 σ/√d 归一化 + CNN 月度重训**算力远超**前面 LGBM 实验。
  → 先 Phase-1 廉价筛查;Phase-2 必上 checkpoint(SIGN-R08),分块落特征。
- **可交易性**:目标已选截面 pump 事件(路径感知、可排序、带风控),非单根方向/终值——可操作性最强(承上轮结论)。
