# 基金抱团 → alpha 三方案 (2026-06-19)

> 用户: 高收益基金抱团能否转化为我们的 alpha/打分/池子优化。3 方案全部冻结 gate + walk-forward。
> 纪律: 宽基随机498只(业绩无关避幸存者) + PIT(ann_date零前视) + 扣动量残差 + placebo负控。生产 V12.31 冻结。

## 裁决: 三方案全 REJECT — 基金抱团持仓对我们净 0 可交易 alpha

| 方案 | 测什么 | 结果 |
|---|---|---|
| **FC-1** 抱团度因子 | crowding_level/weight/delta 正交 IC (扣动量) | level/weight **C_塌缩**(零信号,已priced); delta **B_边缘**(+0.0211 t=2.12,低功率) |
| **FC-2** 机构抱团∩回调池 | crowding_delta 入 V7c 回调池 walk-forward | ❌ Δα **−0.224pp/月**(13/19月负, regime全负); 池内机构覆盖27% |
| **FC-3** 拥挤风控 | 排≥p90拥挤股 vs 随机排除 placebo | ❌ excl_crowd 3.85 < 随机 placebo 3.94(技能Δ−0.09,比随机还差) |

## 机制（为什么没 alpha）

1. **抱团水平 = 动量镜像**：crowding_level 扣动量残差 IC≈0——基金抱团的票（中际旭创/新易盛）是**后进已涨**的，信息已 price-in。这和我们正交 campaign 的反复结论一致（即时可拉信号≈动量投影）。
2. **唯一边缘信号是"抱团流入 Δ"**，但低功率（t=2.12 仅17月），且接 book walk-forward 即消失（FC-2 Δα 负）。
3. **风格正交**：我们小盘回调池 vs 机构大盘抱团龙头（光模块），重叠仅 27%，交叉无协同。
4. **拥挤风控对我们 no-op**：我们本就少持极端拥挤龙头，按拥挤排除 ≈ 随机排除（甚至更差），纯去暴露无技能。

## 描述性发现仍有效（看清市场结构）

虽不可交易，但抱团分析本身揭示了市场结构：**70 只高收益基金极端抱团光模块/算力链**（中际旭创 94%、新易盛 93% 基金持有，Jaccard 0.197 ≈10× 随机），收益=主题 beta + 抱团动量。这解释了**为什么牛市我们跑输**（他们追高主题龙头，我们抄底回调小盘），是风格对照/regime 认知的有用输入，而非选股信号。

## 元结论

基金持仓（真正交于价量的新数据）对 V12.31 **净 0 可交易 alpha**。与正交 campaign(0618) + QuantML 模型(0619) 一致收敛：**增量不在选股层**（价量/正交/模型/基金持仓都试尽），在 **book/风控/部署** + 真正的微结构/另类数据（token 无权限）。
