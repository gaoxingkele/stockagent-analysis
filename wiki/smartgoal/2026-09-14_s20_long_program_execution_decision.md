## 2. 专家立场与裁决

- A 方法：先旧锚风险层、直接安全概率和联合四类，再按错误类型启动严重度、多阈值、路径和序列研究。
- B 量化：高胜率可能小赚大亏；必须同本金、真实成交、保留未退出风险，不能把最高涨幅当收益。
- C 统计：拒绝推荐会改变分母；同日同 k 排序诊断与允许空选的真实政策分开，不能反复看外层挑门槛。
- D 工程：把每条假设变成输入合同、预算、产物、验收与停止条件；先纵向闭环，再扩模型。

主要分歧与裁决：不认定四类必胜；不认定低波动就是新信息；不把 P 盈利替换 O 机会；不把高波动股从训练中删除。高风险样本要被学习和惩罚，是否实际拒绝由冻结政策决定。

## 3. 三条目标轨道与推荐输出

O：安全触达 +15%/+20% 机会分别报告；达到既定安全触达后回落，不取消该机会成功。其他目标阈值是扩展研究，不能偷偷改变原标签。

P：冻结的 D+1 入场至市场 D+20 净终值盈利 U，及全窗口相对入场经济成本跌破 -5% 的 B5。A=U且非B5，B=U且B5，C=非U且非B5，D=非U且B5。与早期 O 的 A/B 命名严格分开。

T：真实成交、费用、T+1、涨跌停、停牌、部分成交、重叠持仓与现金。D+20 无法卖出保留待退出及资金占用，不能按不可成交价格假装兑现。

P 联合概率满足 pA+pB+pC+pD=1；p_up=pA+pB，p_down5=pB+pD。先做风险准入，再以 pA 或效用 pA−λpB−μpD−νpC 排序，μ>λ>ν≥0。高上涨概率不能抵消硬风险门槛。效用不是概率；p_down10 必须另外有对应标签模型或估计，不能由 B5 冒充。

推荐输出保留任务版本、原始概率、校准概率、风险、效用、拒绝理由、数据日期、模型版本与未知状态。TopN=1/3/5/10/20 都是上限，允许 0；空选胜率为 null。沪深与北交所分配置评估，无行业四只上限。

## 4. 广泛算法路线库与激活合同

| 优先级/路线 | 训练方法与假设 | 对照及停止证据 |
|---|---|---|
| 首轮：旧锚风险层 | 真实历史 OOF 机会分 + 浅树/GBDT 风险；危险高分是可辨别的 | 原锚、常数风险、ATR/流动性；控制机会分/波动/市场后无增量则停 |
| 首轮：直接安全概率 | 二分类交叉熵，逻辑回归/浅树为低复杂度基线 | 成熟频率、简单规则；用于判断联合模型是否必要 |
| 首轮：联合四类 | 多分类交叉熵，统一单纯形与温度校准 | 直接 pA、独立双头；未改善入选可靠性/同覆盖前沿则停 |
| 首轮：条件三头 | 建模 P(U)、P(B5|U)、P(B5|非U)，推导一致四类 | 联合四类；条件事件太少或跨折不稳定则停 |
| 首轮有限：成本敏感 | 固定结构比较普通/加权损失，历史 OOF 难负例权重 | 不加权模型，重新校准；不能以加权输出直接称概率 |
| 必做：选择性预测 | 固定模型，比较 pA 门槛、风险硬门槛、硬门槛后效用 | 全日历覆盖与同覆盖风险；只在外层调阈值才赢则无效 |
| 条件：频率与严重度 | 风险概率配合条件损失/分位数；假设相同风险率仍有尾部差异 | 经验分组损失、无严重度；深亏无重复集中或金额不改善则停 |
| 条件：多阈值 | O 的 +15/20/25/30/35 分别定义安全事件；嵌套损失/单调约束 | 单阈值、独立头；先验证安全路径定义是否真的嵌套，不机械强加单调 |
| 条件：首次触达/多状态 | 离散危险率、竞争事件、成熟/删失机制；预测先跌还是先涨 | 普通多期限头、去顺序；日 OHLC 无法识别的先后保留未知或界限 |
| 条件：分位数/分布 | pinball/分布损失估计终值与风险尾部 | 简单经验尾部；边际分位数不能冒充联合安全概率 |
| 条件：漂移适应 | 滚动、时间衰减，之后增量/元学习 | 静态与简单滚动；统一完整 20 日反馈，不优先喂早到负例 |
| 条件：序列表示 | 小 MLP/TCN，之后 Transformer/状态空间模型 | 等窗口摘要树、时间打乱；顺序无增量不扩大网络 |
| 条件：市场门控/图 | 事前市场状态和关系图，研究条件信息 | 市场变量简单模型、无图/随机边；当前行业关系不能回填历史 |
| 研究储备：检索/表格基础模型 | 成熟历史邻居或有限资源探针 | 相同历史窗树模型、有效独立邻居；预训练来源不透明单列风险 |
| 最后：联合路径生成 | Copula/经验重采样之后才试生成模型 | 经验路径；合成路径不增加真实验证样本量 |
| 独立政策：延迟入场/退出 | 预测固定后比较固定延迟、当日重新评分、预设止盈 | 即刻入场/固定到期；保留原失败、未触发和错过上涨，不事后挑最佳买点 |

首轮不同时改变模型、损失、特征与政策。先锁政策比较模型，再锁模型比较政策，最后只对登记的有限完整组合决赛。高级路线须由开发段跨折残差触发；查看外层后设计新模型，该外层即转为开发数据。

“正交特征”按条件增量而非低相关定义：价格/量价 → 波动与流动性 → 市场状态 → 财务/事件 → 关系特征。每组做训练段去除、条件置换及噪声对照，报告跨折稳定性。财务与事件必须有当时可得证据；SHAP 或正负均值差仅解释，不证明独立预测力。

### 三份条件实验单的训练细化

- SEV：先比较全样本损失分位数与经验分组，再比较危险发生率 × 危险条件严重度。固定退出和风险门槛，避免模型与交易规则同时改变；MAE 改善不等于已实现亏损改善。
- REJECT：基础模型固定，用历史 OOF 的危险误判训练普通二分类拒绝器；与基础分阈值、风险阈值、模型分歧比较。控制已有机会/风险/波动后仍有稳定误判区域才启动；只复现原阈值或仅减少覆盖就停止。独立 selection 段选门槛，不先上端到端选择性网络。
- PATH：先单目标与共享多阈值，再比较首次触达/竞争事件。等待时间、阈值边界和先跌后涨残差须跨开发折重复；纯价格触达是嵌套事件，但附加“触达前安全”等条件后须重新证明嵌套。高阈值稀疏、依赖强填 OHLC 顺序或无同覆盖增量则关闭。

这三份是条件候选，不是新增预算授权。与冻结实验 ID 的映射及使用配置槽必须在启动合同登记，不能把此处别名当作额外免费试验。

## 6. 预算、统计和状态机

首轮沿用原协议 12 配置槽、2 种子、3 折、最多 72 次模型级 fit，具体槽位以 initial_slot_allocation 为准；不训练的参考不虚计 fit，多头、校准、父模型及重试另有明确账目。决赛/高级阶段依冻结额度，不能把 72 当成整个长期项目的无限循环额度。改变配置、特征、阈值、N 或交易规则要新 trial，组合总预算在搜索前明确。

搜索前必须填实数和具体日期的待交付合同：estimand_contract、split_manifest、pipeline_budget、activation_contract、power_plan、review_schedule、execution_contract。不能带 TBD 启动正式搜索。资源探针给出时间/内存/超时上限；失败不退还已消耗搜索机会，不盲目重试。

统计四面板：固定全部日期同 k 看排序；真实门槛全日历看拒绝/择时；选择段冻结的同覆盖政策看风险收益；同本金看可用利润。不得仅评双方共同入选日。候选数不足和未知显式标记，不能事后换集合凑 k。

日期块 20/40/60 及重复推荐 episode 检查依赖。60 个成熟信号日只是首次评估入口，不是足够功效。用开发期日期块做效应量/覆盖/行情的功效模拟，事前冻结最小实用改善、最长采集期限或最大成熟样本、查看次数。零风险事件不等于零风险概率。

G3 不变：前瞻同覆盖安全盈利差的 95% 区间下界 >0，风险10差的上界 <0。B5、收益金额、O 机会面板必须报告，但不事后代替 G3。尾部事件不足返回 INSUFFICIENT_EVIDENCE；不延长到显著，不更换阈值追求通过。

每个 trial 保存 hypothesis、target、activation_evidence、source/label/feature/split/code/environment hashes、parent bindings、seed、预算、预测、指标、decision。恢复检查进程身份、原始输入和已提交产物；参数变动不是同一试验恢复。失败保留，缓存依赖改变失效。

运行态：FAILED_INFRA / FAILED_VALIDITY / WAITING_MATURITY；科学态：NO_GAIN / TRADEOFF / INSUFFICIENT_EVIDENCE / 符合冻结门槛的晋级。数据失效或风险警戒可提前暂停，不能提前宣布成功。没有合格模型也是完整研究结果。

## 7. 文献到实验，不凭论文名气选冠军
