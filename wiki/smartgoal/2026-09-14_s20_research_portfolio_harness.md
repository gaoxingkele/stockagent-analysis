# S20 长期研究组合与 Harness 执行方案

日期：2026-09-14。性质：SmartGoal 研究规划与执行优先级，不是训练完成报告。沿用冻结的 `config/s20_v4_harness_plan.json`，不修改预算、G3、生产 R20、池子、网页或 21:00 调度。

## 1. 决策与真实起点

目标不是训练一个“肯定不跌”的分数，而是在披露推荐覆盖的条件下，提高上涨/安全盈利概率，降低危险误判和尾部亏损。允许 TopN 不满、当天不推荐；但不能靠接近零覆盖自称高质量。

本次只读 report：H00 accepted；H01-c7a7d6e3e5724744900a248e75a4c68a 为 FAILED_VALIDITY；H02 仅诊断 intake，正式验收未实现；H03–H10 正式 executor 未实现。历史可得时间、公司行动和身份/集合等仍有验收缺口。这是登记审计状态，不是本次重新审计全部源数据。

最新执行记录已有成熟频率、联合四类、条件三头、成本敏感、独立校准与同折比较等合成测试。它们证明组件可运行，不证明 S20 优于 R20。本轮不再以模型数量或测试数量作为科学进展。

## 2. 专家意见与交叉批评

- A（独立方法提案）：风险增量、联合事件、严重度、路径时机、成熟反馈适应五条路线；难负例来自训练内部 OOF 的高机会危险误判。
- B（主代理量化审查）：必须同时看净收益金额、不可成交与真实退出；用户认可的安全触达不能被固定期亏损回写成机会失败。
- C（独立统计反方）：当前缺真实数据入口、完整统计合同及停止扩建检查点；同覆盖、日期块与 episode 是必要对照。
- D（主代理工程整合）：先数据裁决与最小真实闭环；复杂路线按残差触发；产物验收与科学裁决分开。

保留的分歧：A 倾向先证明旧锚风险增量再开展联合模型；D 不将此设为额外硬依赖。旧锚若不可复现，不得替换成另一个分数冒充原锚，但直接安全盈利/联合模型的合法独立基线仍可研究。相关比较标为不可用，不能使整个新方向永久停摆。

## 3. 三个任务，共享数据但分别裁决

| 轨道 | 学什么 | 不允许混淆 |
|---|---|---|
| O：上涨机会 | 风险界限前安全触达 +15/+20；+25/+30/+35 为扩展 | 安全触达后回落不取消已经发生的机会；最高价不是成交价 |
| P：安全盈利 | D+1 开盘参考入场，到市场 D+20 扣费净盈利及全窗口风险 | 小涨也可成功，但不能替代 O；停牌不延长预测期限 |
| T：可兑现性 | 固定预测下，预先定义入场/退出政策的实际净收益与风险 | 等待、未成交、错过上涨、无法退出均保留，不事后挑最低买最高卖 |

P 四类：U=净终值盈利；B5=全窗口经济价值相对入场成本曾跌超 5%。A=U且非B5，B=U且B5，C=非U且非B5，D=非U且B5。使用 P 前缀，避免与早期 O 的 A/B 命名冲突。B10 是独立风险端点，不能用 B5 概率代替。

推荐链：数据/交易资格 → 独立风险准入 → 安全上涨排序 → TopN 上限/拒绝推荐。对照直接 pA 与 `pA-lambda*pB-mu*pD-nu*pC`，其中 `mu>lambda>nu>=0`。效用不是概率；上涨高分不能抵消硬风险超限。严重度先并列报告，再作为有限扩展，不堆砌未经验证的惩罚项。

## 4. 研究路线库：广泛保留，有限执行

以下编号是研究候选，不代表新增冻结试验槽。启动前映射既有预算；超额必须另行修订协议，不能自动扩容。

| 优先级 / 路线 | 最小实验和对照 | 激活证据 / 否证 |
|---|---|---|
| 首轮：旧锚风险层 | 原锚、ATR/流动性过滤、学习风险、硬门槛与软惩罚 | 需要合法 OOF 锚；匹配日期、机会分、波动与流动性后无增量则停止扩容 |
| 首轮：直接安全事件 | 成熟频率、逻辑回归、浅树、直接 pA | 复杂方法必须对比；频率基准平分时采用预先固定且与标签无关的排序 |
| 首轮：联合与条件风险 | 四类联合、条件三头、直接 pA、独立双头 | 联合保持概率一致性；条件样本不足或不胜直接 pA，保留简单模型 |
| 首轮有限：成本敏感/难例 | 未加权 vs 历史 OOF 难例加权 | 全样本保留，自然分布校准；若仅提高原始分数而未改善外层风险则否证 |
| 条件：风险严重度 | 经验分组损失 vs 条件损失/分位数 | 同风险概率下尾部差异跨折存在；MAE 不冒充实现亏损，少数日期决定结果则不晋级 |
| 条件：学习拒绝推荐 | 分数阈值、风险阈值、模型分歧、OOF 误判拒绝器 | 已知分数/波动之外仍有可识别错误；只减少覆盖或复现已有阈值则否证 |
| 条件：多目标/多期限 | 单 +20、共享 +15…+35、多期限平头 | 阈值附近错例重复；检查嵌套目标概率单调性，边际预测不当联合安全概率 |
| 条件：首次触达/状态转移 | 平头 vs 离散危险率/竞争事件 | 顺序错误重复且非数据问题；OHLC 同日顺序未知给界限，不强填先后 |
| 条件：市场状态/稳健分组 | 固定模型、市场简单头、状态门控 | 事前状态解释持续残差；区分择时与同日个股贡献，不让一个行情包办优势 |
| 条件：滚动/在线适应 | 固定、滚动窗、时间衰减，再复杂适应 | 统一完整成熟反馈；不提前只喂快速到来的负例，跨折无增量则停止 |
| 后续：序列与自监督 | 等窗口摘要树/MLP、TCN、小 Transformer | 先证明时间顺序增量；时间打乱不退化则不扩网络；预训练也隔离未来 |
| 后续：图/关系 | 无图、随机边、事前关系图 | 控制市场/行业/波动仍有残差；当前关系不能回填历史 |
| 后续：成熟案例检索 | 树、邻居频率、检索增强 | 去重近邻 episode、隔离未成熟结果；独立行情邻居不足则证据不足 |
| 末位：表格基础模型/路径生成 | 同窗口同预算树/MLP、经验路径重采样 | 先做资源与预训练污染审查；合成路径不能增加验证独立样本数 |
| 独立 T：延迟/止盈/组合 | 即刻、固定延迟、每日新评分；固定退出 vs 预设止盈 | 原始失败不删除，新入场重新计时；预测固定，同本金和现实成交条件比较 |

难负例重点是“训练内部 OOF 预测机会高、实际危险”，不是所有跌股一律加权。与同日相近机会分/ATR/流动性的安全样本比较；P.B 与 P.D 分开。未知、未成熟和未成交不是负类。不能读取 outer 错例后还把该 outer 当未见测试。

特征研究按组推进：价格/路径摘要 → 波动与跳空 → 流动性/可成交性 → 市场广度和状态 → 事前行业关系 → 有可靠发布时点的基本面/事件。报告组去除、训练段条件置换、噪声组、跨折稳定性；低相关或 SHAP 高不等于“正交增量”。不恢复行业四只上限，行业集中度仅披露；北交所独立配置与验收。

## 5. 论文到实验，不把论文名当效果证明

本轮核查以下原始来源，非五年完整系统综述，未调用 mylib：

- [Conformal Risk Control，ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/f3549ef9b5ff520a7e41ff3cc306ab2b-Abstract-Conference.html)：单调损失的期望风险控制。研究用途是选择/拒绝政策；其保证不能直接搬成每只股票不跌或入选集条件保证。
- [Non-Exchangeable Conformal Risk Control，ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/de04896f011beff76c91e094f72727f4-Abstract-Conference.html)：研究非交换数据下的加权风险控制；股票上的假设、漂移代价和稀有事件仍需检验。
- [DoubleAdapt，2023](https://arxiv.org/abs/2306.09862)：数据/模型适应的增量学习思路。先胜滚动窗，且适配 20 日标签成熟延迟。
- [MASTER，2023/AAAI 2024](https://arxiv.org/abs/2312.15235)：市场引导的股票时序关系建模。只作为关系残差触发分支，不因论文回测结果推定 S20 安全盈利有效。

后续文献工作交付 paper_card：原问题/数据切分/源码版本/许可/信息时间/计算预算/可迁移机制/不能迁移的保证/最小反证。先复现机制，再改 S20 目标，分别记实验，避免同时改所有因素。

## 6. Harness 七个执行包

| 包 / 依赖 | 具体交付 | 验收与停止 |
|---|---|---|
| R1 / H01 | `scope_decision`、来源可得时间与集合证据、缺口台账 | 对事前定义共同范围明确 PASS/FAIL；不得用文件日期或当前下载时间伪造历史可得时间 |
| R2 / H02，依赖 R1 | 多日期 O/P 标签、成熟记录、迁移矩阵、执行黄金案例 | 未来注入失败；未知与未成交保留；公司行动/现金/终止上市等语义通过，不只哈希通过 |
| R3 / H03，依赖 R2 | 精确时间折、一个真实基线纵向闭环、旧方法复现差异 | fit→tune→calibration→selection→outer，全样本可追溯；无法复现旧锚明确缺席，不冒名替代 |
| R4 / H04–H05 | 注册首轮有限矩阵、概率校准、风险覆盖和错误分类 | 同日同 k/同覆盖比较，有限选择政策；完整记失败、成本、空选与缺失 |
| R5 / H06 | 特征消融、残差触发合同、至多两个高级家族 | 无开发证据就跳过；不胜简单控制关闭路线，不追加搜索求胜 |
| R6 / H07–H08 | 锁定报告、episode/NAV、配对日期块、单候选封存 | 统计合同先冻结；排序/概率/收益分别判决，未知作保守界限 |
| R7 / H09–H10 | 真正未来追加预测、模拟成交、成熟队列、预定裁决 | 不回填预测，不反复窥视；不足则等待或证据不足，生产升级另行授权 |

R1 要有有界调查清单和裁决点，不能无期限修补所有历史。若历史时点不可证实，交付明确失败与可行范围提案；改范围须事前共同定义，按协议批准。可另行规划从现在采集真实可得时间的前瞻证据，但它不能补造旧历史，也不能绕过未实现的正式阶段。

近期停止扩建检查点：R3 前不新增高级模型；允许修复阻断纵向闭环的组件。下一科学交付必须是“真实数据基线比较”，或“数据有效性失败及具体缺证”；合成通过不可替代两者。

## 7. 训练、统计与运行合同

沿用首轮 12 配置槽×2 种子×3 折、至多 72 次模型级 fit。多头、校准、选择政策、失败另计；成熟频率不虚计分类器训练。决赛最多三候选，既有校准/政策与高级家族额度不变。不得把本路线库逐项累加为新增授权。

正式搜索前必须落地：`split_manifest`（具体日期与成熟边界）、`estimand_contract`（分母/权重/成交/同覆盖）、`pipeline_budget`（完整组合和资源上限）、`power_plan`（实用效应和依赖）、`review_schedule`、`activation_contract`。这些是待交付合同，不声称本轮已生成可执行 JSON。未填完则拒绝正式搜索。

核心输出：O 安全 +15/+20 触达率；P 净盈利与安全盈利率；B5/B8/B10、MAE及净收益金额；T 尾部亏损/NAV/成本；每日覆盖、空选、错失机会、未知与未成交；每月和市场分组；入选后的概率可靠性。月度波动允许，但整体与最差月份均披露。

比较分四层：同日同 k 测排序；全日历测择时/空选；同覆盖测质量取舍；同本金测可兑现收益。重复股票与重叠 20 日标签不作为独立样本。日期块 20/40/60 加 episode 敏感性，种子不是额外日期。60 个成熟信号日只是首次评估入口，不代表统计功效充足。

冻结 G3 不改：真实前瞻同覆盖安全盈利差的 95% 区间下界 >0，风险10差的上界 <0。若尾部事件少到无法辨别，返回 INSUFFICIENT_EVIDENCE；不能用 B5、漂亮胜率或开发回测替代。已看过的数据永久记为开发暴露。

每个作业记录：experiment_id、hypothesis、activation_evidence、上游哈希、数据/标签/特征/切分版本、代码与环境、完整 pipeline、seed、预算预留、进程身份、预测、指标、失败与 decision。启动前检查依赖和预算；终端退出后验证产物与数值；相同输入已完成则校验复用，输入变化新建 trial。基础设施失败和科学无增量分开，不盲目重跑。
