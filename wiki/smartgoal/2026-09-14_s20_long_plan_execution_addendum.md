## 1. 决策摘要与当前证据

目标不是保证每只股票不跌，而是在明确覆盖与成本下，提高推荐股票的安全上涨/盈利概率，同时降低危险路径发生率和尾部损失。R20、旧 S20 保留为基准，不预设新版更先进。

本轮只读运行 CLI report：H00 accepted；最新 H01-1097e751432f4a0a813ccd407a6d52f1 为 FAILED_VALIDITY；H02 有诊断 intake，但正式语义验收未实现且被 H01 阻断；H03–H10 executor 未实现。此前文档“只有 H00/H01 executor”的描述已过时。该 report 核验登记证据，不是重新审计所有源数据，也不是模型效果报告。

冻结协议哈希：ca386ceef1c6dcd21958db97af5b6eef222a60775719711019fd627f9c8ebaaf。当前主要缺口仍包括历史可得时间、公司行动/规则语义集成、历史集合与退市覆盖。诊断标签算术一致不等于这些缺口已解决。

保留三条口径：

- O：安全触达 +15%/+20%，后来回落不取消已经满足的机会；触达前后风险另列。更高目标 +25/+30/+35 是多阈值研究。
- P：D+1 开盘参考买入，到市场日历 D+20 的扣费终值盈利和全窗口风险；不替换 O。
- T：实际可成交的政策与持仓结果；不假定卖在最高价，不把未成交计为成功。

## 2. 专家讨论与分歧裁决

本轮方法专家独立补充、统计/交易专家独立批评，再由主代理承担工程整合；方法专家随后复核交叉意见。未将不同角色的意见当成独立实证。

| 观点 | 支持理由 | 反对意见 | 裁决实验 |
|---|---|---|---|
| 旧机会锚加风险层优先 | 可直接检验旧排序仍有多少可用信息 | 风险层可能只是 ATR 过滤 | 同 OOF 锚、同覆盖、相近波动流动性比较学习与简单过滤 |
| 联合四类优于单一上涨头 | 区分危险上涨和危险下跌 | 复杂度增加；损失金额仍丢失 | 固定决策规则比较直接安全事件、四类、条件分解 |
| 对危险样本加重训练惩罚 | 对准高分危险误判 | 可能损害校准、机会捕获 | 普通损失 vs 成本敏感；每个模型独立重新校准 |
| TopN 约束排序更贴近推荐 | 训练聚焦当天头部质量 | 可微代理约束不保证真实风险约束 | 固定政策，分类排序 vs 约束排序；只满足训练约束不算通过 |
| 某些月份可以差 | 不要求所有行情一致 | 少数月份大亏可能吞掉全年盈利 | 全年/全日历净收益、最差月、尾部与日期块区间共同报告 |

共识：风险门槛是决策层，成本敏感损失是训练层，不能同时随意改变后宣称模型进步。先固定模型比较政策，再固定政策比较训练损失；最后才比较完整流水线。

## 3. 首轮训练包：先回答五个问题

以下为待登记的配置槽分配建议，不是已冻结超参数或已完成试验。沿用 12 槽上限，不新增预算。

| 槽位 | 模型/任务 | 对应问题 |
|---|---|---|
| 01–02 | 直接 P.A 二分类：逻辑回归、浅 GBDT | 简单安全概率是否已经足够？ |
| 03–04 | 旧 S20 OOF 机会锚 + 学习风险：简单模型、树 | 风险能否在机会排序之上提供信息？ |
| 05–06 | 普通联合四类：多项逻辑、树 | 联合事件是否比直接 pA 更有效？ |
| 07 | 条件分解：P(U)、P(B5\|U)、P(B5\|非U) | 条件结构是否有增量、是否有足够样本？ |
| 08 | 独立上涨/风险双头 | 独立边际作为对照；不相乘冒充安全联合概率 |
| 09–10 | 联合四类的两档预登记成本敏感损失 | 训练惩罚能否减少危险高分误判？ |
| 11–12 | 预留：OOF 难负例与匹配加权对照 | 是否存在可重复学习的危险错误区域？不触发则不消耗 |

所有可训练旧锚、OOF 生成和基线拟合必须纳入总账；上述分配若与原阶段预算归属冲突，先重新分配空槽，不默默追加。R20/旧 S20、历史成熟频率、ATR/流动性过滤为强制对照；非训练规则不虚计 fit。

P 四类：A=盈利且无 B5；B=盈利且有 B5；C=非盈利且无 B5；D=非盈利且有 B5。B5 指全窗口低于入场经济成本 5%，不是峰谷回撤。四类概率必须非负且和为 1。条件分解从同一组条件头重建，不拼接不一致的校准概率。

决策比较保留直接 pA、风险门槛后排序、风险门槛后效用排序。效用为 pA−λpB−μpD−νpC，μ>λ>ν≥0；不是上涨概率。高上涨预测不得抵消已超过门槛的风险。系数大小不保证实际风险下降，必须外层验证。

## 4. 长期路线库：扩散到哪里，怎样停止

每条路线都填写 activation_contract；最多启用冻结协议允许的两个高级家族、六个配置。这里列出路线不代表全部批准训练。

| 路线 | 具体训练/实验 | 启动证据与停止条件 |
|---|---|---|
| 训练层风险约束排序 | 同日成对/列表排序，增加危险样本头部暴露的代理约束；与普通分类和成本敏感比较 | 概率尚可但头部危险错误持续；不胜固定硬门槛或仅降低覆盖则停止 |
| OOF 难负例强化 | 历史 OOF 中高机会分危险失败加权；随机等量、同 ATR 分层加权为对照 | 错误集中在可识别区域且跨日期重复；去掉一行情段就消失或校准恶化则停止 |
| 多目标/多期限 | 同口径 +15/20/25/30/35 与风险3/5/8/10，或多个期限共享表示 | 阈值附近错误反复；检查阈值概率嵌套与分位数交叉，不胜单目标不扩容 |
| 首次触达/多状态危险率 | 建模先涨、先跌、等待与触达后回落；比较多期限普通分类 | 路径顺序确有残差；日 OHLC 同日先后未知保留界限，不允许伪造顺序 |
| 风险严重度/分位数 | 同报风险频率、条件损失分布和总体尾部贡献；经验分组先于复杂头 | 少数深亏吞噬收益；独立坏事件不足则只作描述，MAE 不充当已实现亏损 |
| 状态分组稳健训练 | 用事前市场趋势/波动/流动性分组；普通损失、时间衰减、最差组损失比较 | 相同状态跨折持续差；若只是牺牲总体覆盖与收益换最差组提升，报权衡 |
| 漂移适应 | 固定、滚动、时间衰减，再 DoubleAdapt 类方法 | 成熟反馈有持续漂移；完整20日反馈延迟统一，无增量不升级元学习 |
| 延迟反馈风险更新 | 单独生存/删失任务处理已发生事件和未成熟记录 | 20日延迟确有代价；不得提前喂负例而把未成熟行当安全，统一反馈后无增量则停止 |
| 序列表示 | 小 MLP/TCN 再 Transformer；同窗口摘要树、时间打乱对照 | 顺序信息在开发折有增量；打乱无明显退化则不扩大网络 |
| 事前关系/图 | 市场与行业公共因素控制后，无图、真实图、随机边比较 | 存在关系残差；不能将当前关联关系回填历史，不胜随机边则停止 |
| 历史检索/表格基础模型 | 检索已成熟历史 episode；同窗同样本 GBDT 对照，先资源探针 | 有多种独立行情邻居；近重复贡献全部优势或资源不可行则停止 |
| Copula/路径生成 | 联合路径建模与历史块重采样、简单分位数比较 | 简单方法已被证据否定才启用；合成路径不增加独立验证样本量 |
| 延迟入场/止盈/组合 | 预测冻结后，预设规则、重评分触发与固定持有对照 | 属独立 T 政策；原失败、未触发、错失、不能退出全部保留；理想成交才有效则否定 |

“正交特征”按条件增量定义：价量趋势、波动/跳空、流动性、相对强弱、市场状态逐组加入/去除，训练历史内做条件置换与噪声组对照。低相关、SHAP 排名或正负样本均值差异，不能单独证明新增预测能力。行业暴露用于诊断，不恢复行业最多四只限制；北交所独立配置验证。

## 7. 指标、反证与正式晋级

- 分别报告 O安全触达率、P扣费盈利/安全盈利、B5/B8/B10、尾部损失、T净收益与NAV，不只看胜率/AUC。
- 同日同k评个股，全日历评择时/空选，同覆盖评风险收益，同本金评可用性；空选胜率为null。
- 报信号、股票、日期、episode、非重叠批次、未成交/未知数，按完整日期块20/40/60与episode做敏感性，不把同日数千行当独立样本。
- 未知给保守界限；没有观察到亏损不等于风险为零。60成熟信号日只是首次评估入口，不保证统计功效。
- 已看历史全属开发；正式 G3 不变：未来同覆盖安全盈利差95%下界>0，风险10差95%上界<0。B5不能替换风险10。新增金额约束若成为晋级门槛，需另行冻结，不暗改协议。
- 只降低覆盖、只避低流动性或优势全靠市场择时，必须明确归因；无增益、权衡、证据不足都是有效科学结论。

## 9. 论文线索与边界

本轮核对了原始来源，供路线形成假设，不是五年系统综述，也未调用 mylib 检索运行器：

- [Conformal Risk Control，ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/f3549ef9b5ff520a7e41ff3cc306ab2b-Abstract-Conference.html)：风险控制校准候选；不能直接转为金融入选股票逐只安全保证。
- [High Probability Risk Control Under Covariate Shift，2025](https://proceedings.mlr.press/v266/almeida25a.html)：用重要性加权校准损失处理协变量漂移；论文实验不是股票。应用于 S20 是待检验推论，条件分布改变/权重失准需另外处理。
- [DoubleAdapt，KDD 2023](https://arxiv.org/abs/2306.09862)：数据与模型适应的增量学习；本项目需额外检验20日反馈延迟，不照搬论文收益结论。

长期文献工作包应输出 paper_evidence：任务/数据、真实时间拆分、延迟反馈、成本与代码版本、可复现实验、与本项目不相符的假设。先验证简单对照，再复制一个最小方法，不能以论文名气或综述长度代替本地证据。

最终建议：先做风险层是否有信息、直接安全概率是否足够、惩罚是否改善同覆盖前沿这三项裁决。广泛路线保留，但用可证伪的启动条件和有限预算控制执行。SmartGoal 的实质影响是将训练层/决策层拆开，并把新路线变为有反证、可停止的工作包。

2. 首先执行旧机会锚加风险层、直接安全概率与联合四类比较；成本敏感训练仍在首轮既定槽内。严重度、序列、图、元学习等依残差触发，不能全部启动。
3. 保留高上涨且高风险的训练样本，惩罚其入选，而不是删掉它们使问题变简单。概率、风险概率、排序效用分别输出；任何分数都不承诺个股不跌。
4. 第 3 节槽分配仅是提案；执行以冻结 JSON 的 initial_slot_allocation 为准。改变槽归属先登记有版本的预算修订，不静默覆盖。

### 长期文献工作单

按问题逐包检索近五年原始论文与作者代码：选择性预测、联合/生存任务、漂移适应、时序表示、关系建模。每包产出 paper_evidence 表和一个最小复现提案；未证明适配不进入训练队列。本轮额外核对 [Confidence-aware Contrastive Learning for Selective Classification，ICML 2024](https://proceedings.mlr.press/v235/wu24s.html)：其选择性分类思路可形成“拒绝是否改善同覆盖风险”的假设，但论文图像任务结果不是股票验证。另核对 [DoubleAdapt 作者代码](https://github.com/SJTU-DMTai/DoubleAdapt)，仅作为未来复现入口，不表示本轮运行了该算法或 mylib。

最终放行顺序：数据与标签有效 → 简单链可复现 → 条件风险增量 → 校准和政策 → 压力测试 → 一位候选冻结前瞻。风险10事件太少时，G3 可能无法证明严格改善，应返回证据不足，不临时换阈值、基准或放宽门槛。

## 本轮执行裁决：把长期路线变成有预算的研究组合

本轮使用 SmartGoal：方法专家独立提案，主代理承担交易/统计反方和工程整合；额外专家因并发名额不足未启动，不冒称四位独立专家均参与。只做规划和只读检查，不启动训练，不接生产、不改冻结协议。2026-09-14 本轮 validate-plan 通过；report 核验 H00 已接受，最新 H01-c7a7d6e3e5724744900a248e75a4c68a 为 FAILED_VALIDITY，H02 仅诊断 intake，H03–H10 正式 executor 未实现。上述是阶段证据状态，不是重新审计原始数据，也不是性能验证。

### 主张、反方与裁决

- 方法方：优先旧锚加风险、直接安全事件与联合四类、条件三头三个实验。反方：旧锚必须有合法 OOF 来源，不能用全历史拟合后回算的分数；当前缺口下先做不依赖旧锚的简单链，锚恢复单独列依赖。
- 量化反方：同日同 k 是归因对照，不是要求风险门凑足 k。按候选实际通过数量匹配基准；原始固定 TopN、所有日期和空选照常报告，避免只挑共同活跃日。
- 统计反方：惩罚减少坏事件频率不代表减少亏损金额。除风险概率外，先用经验分组统计风险严重度，事件量不足时不给不稳定的条件损失模型扩容。
- 工程裁决：固定模型比较政策，再固定政策比较训练目标；完整流水线登记后才比较冠军。不能同时变标签、损失、过滤、退出后把提升全归给模型。

### 六个优先交付及退出条件

| 优先级 | 工作单 | 可验收交付 | 停止/分流 |
|---|---|---|---|
| 1 | 数据范围裁决 H01/H02 | 历史时点、身份、日历、经济与交易覆盖矩阵；每个缺口的证据、负责人、有限审计批次 | 无法证明的历史保持诊断；不反复采集旧数据冒充过去可得记录 |
| 2 | 最小真实链 H03 | 全候选、成熟标签、固定切分、小模型、校准、选择、评估；旧锚来源单列 | 泄漏/标签口径差异未解释则不扩模型 |
| 3 | 风险增量 H04 | 原分、简单过滤、学习风险、直接安全事件、联合/条件模型的相同条件比较 | 不胜 ATR/流动性则关闭相应复杂路线，不掩盖负结果 |
| 4 | 概率与特征 H05/H06 | 入选子集校准、风险覆盖、分组消融、危险上涨错误卡 | 校准不成立则只能叫排序分；低相关或 SHAP 不单独证明正交增量 |
| 5 | 兑现与压力 H07 | 固定预测后的成交、等待/错失、退出、同本金组合和尾部 | 仅理想成交有效或少量大亏吞噬利润则不称实盘改善 |
| 6 | 冻结与未来 H08–H10 | 一位候选、基准、冻结时点、追加预测、成熟队列和预注册裁决 | 可 NO_GAIN/TRADEOFF/INSUFFICIENT_EVIDENCE；不自动替换 R20 |

每项采用“先假设与输入合同，再实现与失败注入，再小规模端到端，再批量”的顺序。数据阻断期间可以建设隔离执行器，但不能标正式完成。开发周期按这些交付推进，前瞻成熟时间独立计算；不承诺计算几天就获得未来证据。

### 长期研究组合分配

核心层优先浅模型与联合风险，校准/拒绝为必备组件。第二层根据开发集残差启用多目标阈值、危险率、风险严重度、稳健分组、成熟反馈滚动适应。第三层保留 TCN/Transformer、事前图、成熟近邻检索、表格基础模型、联合路径生成；每次最多进入已批准的两个高级家族和六个配置，不把候选库当全部训练清单。强化学习与模型、止盈、止损全联合搜索暂缓。

序列方法必须对照同窗口摘要树和时间打乱；图方法对照公共因子、无图、随机边；检索须去行情 episode 重复；漂移适应须施加相同标签反馈延迟；生成数据不能增加独立市场验证样本。高级路线的启动判断也记入搜索账，只使用内部开发证据。

保留 O 安全触达与 P 安全盈利两个研究问题，T 独立兑现；不能因为用户认可触达后回落，就宣称持有到 D20 也盈利。风险门先于效用排名；高上涨分不能抵消超过准入门的下跌风险。效用分不命名为置信概率。

### Harness 接手合同

现有代码位置 research/s20_harness/，测试 tests/s20_harness/，研究产物 output/experiments/s20_safe_v4/。下列是实施要求，不是声称均已接通的 CLI：

1. 预检登记 experiment_id、pipeline_trial_id、假设、轨道、控制组、上游哈希、可用日期与标签成熟时间。
2. 冻结 feature/label/split/code/environment 与完整流水线允许组合；预算包含旧锚重训、OOF、消融、多头底层 fit、校准和政策尝试，禁止隐含笛卡尔积。
3. 沿用首轮 12 槽×2 种子×3 折，至多 72 次模型级 fit；不依赖训练的基准为零 fit。若锚重训挤占预算，减少其他槽，不暗增总额。
4. 分离 fit→tune→calibration→policy→outer。新提出的修改若看过 outer 结果，相关数据改记开发曝光，不再自称独立验证。
5. 每次保存预测、样本数/未知数、概率与排名、校准、政策、错误分类、时间资源、产物哈希及科学结论；同时报同日同 k、全日历、同覆盖和同本金四种比较。
6. 恢复核实 PID 身份、心跳、源哈希与最后原子提交；已存活任务只续查，不重开。基础设施最多重试两次，改变参数新建试验；无增益不靠自动反复调参消除。
7. 正式训练前必须填好具体 split、完整 pipeline_budget、power_plan 和 review_schedule。缺数值属于尚未满足的执行前置条件，不由执行器自动猜测。
8. 原 G3 不变：未来同覆盖安全盈利差 95% 下界>0，风险10差 95% 上界<0；按日期块20/40/60及 episode 检查依赖。60成熟日只是首次评估入口，不保证功效。B5、损失金额、最差月强制披露但不偷换既定门槛。

下一步可使用的只读入口：`python -m research.s20_harness.cli validate-plan --plan config/s20_v4_harness_plan.json` 和 `python -m research.s20_harness.cli report --plan config/s20_v4_harness_plan.json`。不要把尚未实现的下游阶段当作可一键训练；先交付范围裁决和最小真实链。
