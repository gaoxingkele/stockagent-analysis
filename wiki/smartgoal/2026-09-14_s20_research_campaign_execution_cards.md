# S20 长期研究：本轮讨论与 Harness 执行卡

日期：2026-09-14。性质：研究计划，不是性能报告。本轮主代理承担工程 D，独立方法代理承担 A，独立风险代理联合承担 B/C；不声称四位独立专家。沿用冻结协议，不更改生产 R20/S20、池子、网页或 21:00 任务，不启动训练。

## 决策摘要与已核对状态

目标是让有限推荐中的安全上涨/盈利更可靠、危险误判更少，而非承诺逐股不跌。TopN 是上限，允许空选，但空选的准确率为 null。保留形态开放、无行业四只上限、北交所独立配置与评价。

本轮实际执行 validate-plan 和 report：协议有效，规范哈希 ca386ceef1c6dcd21958db97af5b6eef222a60775719711019fd627f9c8ebaaf；H00 accepted，H01 FAILED_VALIDITY，H02/H03/H05 仅诊断 intake，H04/H06–H10 无正式阶段执行器。进度头部已有 18-job 合成消融与控制分层，不代表市场有效性。旧文档/专家引用的较早测试数字不能当成当前完整测试结果。

主计划继续使用 docs/research/s20_long_harness_execution_decision_20260914.md；本卡补充执行优先级和停止扩建规则，不重复扩展冻结预算。

## 专家意见与交叉批评

- A：先证明风险层含有机会分和低波动过滤之外的信息；直接安全事件、联合四类、条件模型公平竞争；残余错误决定是否需要路径模型。
- B/C：少推荐可能制造高胜率；四类不包含损失金额；模型之间同覆盖比较不等于交易同本金比较。H01 未通过时，无限加合成测试不会产生市场证据。
- D：把每种论点变成登记的反证实验；区分工程通过、诊断发现、正式有效。概率、风险门和效用三个对象分别保存、比较。

| 分歧 | 解决实验 | 无增益如何处理 |
|---|---|---|
| 增大下跌惩罚是否会学得更好 | 普通训练、普通输出按权重倾斜、真正加权训练；固定特征和政策预算 | 仅重标度即可复制提升，则只归因政策改变 |
| 联合四类是否必要 | 直接安全事件 vs 四类 vs 条件三头；相同窗口和特征 | 简单模型占优就保留简单模型 |
| 高置信拒选是否有信息 | 风险门、ATR/流动性门、学习拒绝器；同日同数量及全日历对照 | 只改善择时/覆盖则单列权衡，不称个股识别提高 |
| 高胜率是否实用 | O/P/T 迁移与同本金损失金额 | 小盈大亏或不可成交吞噬收益，不晋级 |

## 标签与分数：三个轨道不混用

O 是安全触达 +15/+20，扩展 +25/+30/+35：安全达标后回落不撤销既有触达成功。P 是固定 D+20 扣费盈利与风险的联合事件。T 是实际成交、退出、费用、现金和持仓。触达最高价不是可实现卖出价。

P 轨冻结四类：A=盈利且无 B5；B=盈利且有 B5；C=不盈利且无 B5；D=不盈利且有 B5。这里的 A/B 与早期 O 路径命名不同。B5 与 B10 分开建端点，不能用 B5 改善替代正式 B10 验收。

选择顺序为可得数据/执行准入 → 风险硬门 → 排序 → TopN 上限。分别竞争 pA 与 pA−λpB−μpD−νpC，μ>λ>ν≥0。权重是内部验证的候选，不是固定真理；效用分不是上涨概率。不能通过很高的上涨分抵消超限风险，也不能把两个边际概率相乘冒充安全联合概率。

| 优先级 / 执行卡 | 必做对照与数据 | 交付与验收 / 停止条件 |
|---|---|---|

| 2 BASELINE-BRIDGE：最小真实闭环 | 同候选/日期的旧 R20/S20 可复现部分、频率、逻辑回归、浅树、ATR 门 | baseline_metrics.csv、opt_transition.csv；特征到预测独立重算一致；旧锚缺失写明，不能以新训练冒充旧版 |
| 3 RISK-INCREMENT：风险有无额外信息 | 原 OOF 锚、常数风险、简单过滤、学习风险、去锚对照 | conditional_increment.csv；控制机会、ATR、流动性、状态后，同日同 k 仍有增益才扩容 |
| 4 TASK-LOSS：任务结构与训练损失 | 直接安全、联合四类、条件模型；普通/重标度/加权训练 | task_loss_comparison.csv；并报校准、风险金额、覆盖；不胜简单路线即停止复杂路线 |
| 5 SELECTED-RELIABILITY：推荐中是否可信 | 同模型原始/校准概率、固定入选集合误差、分别重新选择的端到端结果 | selected_reliability.csv、risk_coverage.csv；全部候选/拒绝/未知/空选留存；校准不足只称排序分 |
| 6 FREEZE-TEST：未来能否复现 | 固定候选与基准，成熟反馈、同本金执行与日期块评估 | power_plan.json、封存清单、NAV、最终裁决；不通过不替代现版 |

这些产物名为交付合同，不声称对应正式执行器均已实现。旧锚不可复现时，独立模型诊断可继续；正式完整基准的缺口不因此消失。

## 充分发散的路线库：由什么证据启动

| 路线 | 最小反证实验 | 启动依据 / 停止条件 |
|---|---|---|
| 多阈值与序数学习 | 单目标对共享多目标，检验高目标概率不超过低目标 | 错误集中阈值边界；仅一致性好看但主目标不改善则停 |
| 首次触达 / 竞争风险 / 多状态 | 静态分类、5/10/20 日多头、事件时间模型 | 先后顺序有可得信息；日线双触达不强填顺序 |
| 损失严重度与分位数 | 经验尾部对条件分位数/分布预测 | 同风险概率内亏损金额差异显著；只改善点误差不改善尾部则停 |
| 难负例与成对排序 | 训练内部 OOF 挖掘高分危险股，对普通损失 | 不使用外层错误挖样本；加权后在自然分布重新校准 |
| 不确定性拒选 | 模型分歧/训练支持度对简单风险门 | 控制平均风险与波动后有增量才用；分歧不是置信区间 |
| 稳健状态与漂移适应 | 固定、成熟反馈重校准、成熟反馈重训 | 重训不胜重校准则不做复杂适应；所有方法使用相同反馈延迟 |
| MLP / TCN / Transformer | 同窗口摘要树、序列模型、训练内时间打乱控制 | 顺序提供增量才扩容；模型大小本身不构成证据 |
| 关系图 / 市场联动 | 公共市场/行业因子、无图、真图、随机边 | 事前关系在公共因子之外有信息；事后行业/未来相关性禁止 |
| 历史检索 / 表征迁移 | 近邻、浅树、成熟历史检索/预训练表征 | 检索库仅成熟历史；邻近同股 episode 重复不能充当独立证据 |
| 条件路径生成 | 简单条件分布对生成路径的顺序和尾部校准 | 基础模型尾部不足且模拟校准过关才做；合成路径不增加独立市场样本 |
| 延迟入场 | 即时、固定延迟、每天新评分触发 | 使用当时分数；原失败不删除，未触发/错失机会全部记账 |
| 组合共同亏损 | 冻结个股后测共同亏损，再单列暴露惩罚 | 组合收益不归功于个股概率；不恢复行业硬上限 |

强化学习与模型/退出/仓位联合搜索暂缓，先验证固定政策下信号是否有效。高级路线最多启动冻结协议允许的两个家族、六个配置，而非整张表一起跑。

## 特征“正交性”的验收

候选组为价格路径、尾部波动、量价与流动性、市场广度/状态、事前行业相对强弱、具备可靠发布时间的基本面/事件、OOF 旧模型分数、训练支持度。

基础组 → 加入组 → 移除组 → 噪声控制，保持非特征因素不变；训练期拟合所有变换和分层边界。检验跨折增量、入选错误变化、同覆盖与成本后效果。低相关、SHAP 高或一次消融提升都不独立证明正交信息。

当前工程的 keyed-uniform 噪声并非分布匹配控制，控制分层也不是条件信息证明。缺层、空选、数量不同必须显式报告；不得强行合并为正增益。更强的条件置换/残差控制需要另登记并检查其有效性。

## Harness 执行与预算

每张卡依次经过：合同和反证 → 失败注入测试 → 合成小链 → 数据准入后的真实小链 → 有界批量 → 独立重算 → 科学裁决。

必填字段：experiment_id、O/P/T 版本、假设/对照、数据/可得性/标签/特征/代码/环境哈希、精确时间折、种子及作用、显式组合、模型级和底层拟合/校准/政策预算、资源上限、产物、验收、停止和恢复规则。字段缺失不得自动猜值运行。

时间顺序：fit → tune → calibration → policy → outer。特征在预测前可得，训练标签在当时已成熟；旧模型训练分数用严格 OOF。全部已看过历史属于开发证据，不重新命名为独立测试。

预算不变：首轮最多 12 配置×2 种子×3 折、72 次模型级 fit；OOF、旧锚、消融、失败和重试计费，多头底层 fits 另记。入围最多三名、总计三种子；每候选校准最多三种、政策最多六种，组合显式列出。首次训练并发一，内存探针通过后至多二。不能把本卡研究目录隐式展开成新预算。

状态分开：执行完成不等于研究成功；NO_GAIN、TRADEOFF、INSUFFICIENT_EVIDENCE、FAILED_VALIDITY 都是有效交付。基础设施失败至多按原协议重试两次，科学失败不自动改参数；活跃任务继续观察原进程，不因等待超时重复启动。

## 验证与放行

同时交付全日历覆盖、同日同 k 归因、同本金 NAV 三张视图。前者检验少荐/空选，第二张隔离择股能力，第三张检验持仓、成本和现金利用。事后同 k 只是归因，不是可部署策略。

指标包括 O 的安全触达，P 盈利/安全盈利/B5/B10，损失金额、入选概率校准，T 成交和净收益；按月、市场、状态报告。允许某些月份差，但不能靠一个月份解释全部优势。未知结果保留上下界，它们不是统计置信区间。

同覆盖预先指定参考哪一方的逐日数量；基准没有足够合格股票的日期标记不可比，不能放松其准入。相同本金不意味着少选后自动放大单股仓位；仓位调整属于另一个政策。统计不显著不自动等于无增益：精度足以排除预登记最小实用增益才裁为 NO_GAIN，否则为证据不足。

日期块 20/40/60 敏感性与同股 episode 检验处理相关性；随机种子不增加独立市场样本。冻结前登记最小实用效应、功效模拟、坏事件数量需求、固定查看点。G3 保持未来同覆盖安全盈利差的 95% 下界 >0 且 B10 差的 95% 上界 <0；60 个成熟信号日只是首次查看入口，不保证统计充分。

## 停止扩建与下一批工作

新增执行裁决：先盘点现有最小链和数据缺口。若无新增来源证据、既定诊断已可验证目标组件，就不继续扩建通用 harness 来绕过 H01；交付缺口/可运行范围/研究限制。只有明确新实验必须的缺失组件或新数据证据才重开对应工作。不停止正常已授权监测，不自动新增采集定时任务。

下一批按顺序：DATA-EXIT 范围裁决 → BASELINE-BRIDGE 准入清单 → RISK-INCREMENT/TASK-LOSS 精确注册卡 → 数据满足时真实小链。数据未满足，只完成必要合同和当前组件验证，不启动正式大搜索。计划中的日期折、功效数值和资源上限须登记后放行，不能用模糊工期代替成熟标签等待。
