# 指定 +15% 才是入池目标；沉默是任务支持，不是数据质检

- **日期**: 2026-09-20
- **provenance**: user-revised（用户要求提高入选上涨幅度、提出沉默池，并要求 checkpoint 写入 wiki）
- **裁决**: 🧩框架（因果筛选已落地为诊断回放；无挑战者迁移，发运仍 π0；非正式 H04）
- **关联代码/实验**: `research/s20_harness/silence.py`；`scripts/replay_s20_v4_screen.py`；`docs/research/s20_v4_screen_pred_20260920.md`；checkpoint `wiki/smartgoal/2026-09-20_s20_checkpoint.md`

## 一句话
推荐池要的是「高概率摸到指定 +15%」，不是到期小涨；闷在 8% 以下且未破 −10% 的票是低信息轨道，不能用尚未发生的最高价剔当天样本，也不能当成脏数据洗掉。

## 为什么引入 (第一性原理)
用户要的是：票一旦进池，应尽量有高概率涨过指定幅度（冻结为 +15%）。旧口径把 A∪B（含 3%～7% 磨）当成功，外层 Top20 盈利 56.3%，但指定 +15% 止盈只有 13.4%。同时提出把「最高涨不到 8%、也没破下限」的票放进沉默池。若把已实现的窗口最高价用于当天入池，是泄漏；若把沉默当质检，会掩盖 H01 真正的数据有效性问题。

## 核心思想 (讲直觉, 不堆公式)
1. **指定上涨与持有盈利分开。** 摸到 +15% 止盈才是指定幅度；到期小绿是另一件事。
2. **沉默是支持限制，不是坏标签。** 路径真实，只是 20 日没有波段。C 的约 81% 是沉默，A 的约 21% 也是沉默。当前 Top20 约 65% 沉默，因为惩罚高波动后排序爱低波动垫子。
3. **因果筛选只有两种。** 成熟后实体冷却（`label_available_at < prediction_at`）；或预测 P(沉默) 当独立门。当天最高价禁止使用。
4. **换总体不是免费改进。** 事后删沉默可把外层盈利率抬到 ~75%，−10% 从 5.9% 升到 ~15%。按 P(+15%) 排序外层命中 50.3%、回撤 49.4%。Dream-RSI：回放双约束改善且覆盖够，外层再确认；否则留 π0。

## 我们怎么吸纳 / 改造
- Dream-RSI：冻结 multinomial_base 轨迹当世界，只搜选择政策（冷却、P(沉默) τ、P(+15%) 排序）。
- 独立风险：P(B10) 滚动 Platt 后再卡门，排名分不能买通。
- 覆盖分母钉死 π0 的 20×日，避免缩小 N 虚增胜率。
- 未重训生产 S20，未把配对四类重训（已负结果）当发运排序。

## 结果与裁决
- **发运 π0。** 因果沉默与 P(+15%) 排序在回放段都不能在 −10% 不差于 π0 的前提下提高指定涨幅命中。
- 外层 π0：指定 +15% **13.4%**，配对 −10% **5.9%**，持有盈利 56.3%。
- 裁决：沉默池作为任务定义有意义；作为当前双约束下的免费提升不成立；作为数据质检不成立。`formal_training_authorized=false`。

## 移植提示 (必填)
换市场时搬这五条：
1. 先写清「指定幅度」是触达止盈还是到期正收益，禁止混成一个胜率。
2. 低波动占资是总体选择，不是缺失/错价；质检走另一本账。
3. 任何冷却或沉默门只用已成熟标签或事前特征。
4. 删低波动垫子会同时抬盈利率和回撤；必须预先登记约束，禁止外层改阈值。
5. π0 留在网格里；回放改善必须外层再验。
**本项目特有不可移植：** A 股 T+1、+15%/−10% 用户配对、8% 沉默切、诊断抽样（代码尾数模 7）、H01 未过故数字不可当生产证据。
