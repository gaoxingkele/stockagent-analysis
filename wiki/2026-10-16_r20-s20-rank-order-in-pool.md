## 做法

每天按模型分数把全市场排名，分成 1–10、11–20、21–50、51–100、101–200、201–500、501–1000、>1000 八档，看每档的成功率（先涨 15%）、先止损比例、每笔收益（名单口径 U15D10），日内均值再对日取平均。再看「前 20 减 21–100」和「前 10 减 21–100」，同日配对，Newey-West(19)。

## 结果

**R20（r20_pred 名次）：最顶端反而最差，两段都一样。**

| 名次 | 样本内成功率 / 先止损 / 每笔 | 样本外成功率 / 先止损 / 每笔 |
|---|---|---|
| 1–10 | 24.3 / 53.0 / −2.03 | 27.7 / 59.4 / −1.90 |
| 11–20 | 26.2 / 48.0 / −1.20 | 30.2 / 56.2 / −1.26 |
| 21–50 | 31.0 / 43.0 / +0.23 | 31.9 / 54.6 / −0.77 |
| 51–100 | 29.5 / 40.3 / +0.28 | 34.0 / 55.1 / −0.51 |
| 101–200 | 29.3 / 39.4 / +0.52 | 33.0 / 54.8 / −0.63 |
| 201–500 | 26.4 / 39.7 / +0.03 | 32.4 / 54.2 / −0.65 |
| >1000 | 21.1 / 40.8 / −1.14 | 23.6 / 48.9 / −1.31 |

- 前 20 减 21–100：成功率 −4.3（t −0.8）/ −4.5（t −1.9），每笔 −1.51（t −1.1）/ −1.01（t −1.8）；前 10 减 21–100：−5.0（t −1.0）/ −5.6（t −2.1），先止损 +10.2 / +4.5，每笔 −1.97 / −1.29。
- 前 100 内名次与成功的秩相关：样本内 −0.021（t −0.9），样本外 +0.048（t +3.2）——即样本外名次越靠后（预测越低）成功率反而越高，样本内没有关系。
- 不是波动代理：前 10 与 21–100 的 NATR 几乎一样（4.4 对 4.5，6.3 对 6.5）。预测值本身：样本外前 10 的 r20_pred 均值 16.0，21–100 为 12.8。
- 没有一个对比两段都过 |t| ≥ 2；方向两段一致（前段更差），样本外较强。

**S20（stage1 名次）：两段不一致。**
- S1（2025-03～08）：前 10 成功率 29.9、每笔 −0.02，低于 21–100（35.5、+1.3）；每笔收益随名次靠后反而上升（>1000 档 +2.18，高波动的新股/小盘多）。
- S2（2026-01～08）：前 10 最好（44.8、+1.68），随名次靠后单调下降，前 20 减 21–100 成功率 +3.4（t 1.5）、每笔 +0.82（t 1.6）。
- 前 20 减 21–100：S1 −4.2（t −1.2），S2 +3.4（t 1.5），符号相反。

## 怎么读

1. R20 的价值在「入选前 100 这个集合」，不在名次：集合内更靠前的不会更好，最顶端甚至偏差。池 A 用「r20 预测或最大涨幅 ≥25%」做门槛，也等于只取最高预测的一端，需要留意。
2. R20 的目标是 20 日收益的回归，先涨 15% 还是先跌 10% 是路径问题；最高预测的名字先止损比例高（样本内 53%、样本外 59%）。这与前面「近期强势」因子在池内有效、而前 20 名单增量接近随机取三分之一的结论一致：池内排序信息有限。
3. S20 的 stage1 名次在 2026 年有效、2025 年无效，与风格/行情有关，还是没有答案。
4. 只有 R20 样本外那一个相关（t 3.2）略显著，其余都不显著；不能写成规则。

## 局限

名次档的日内均值再对日平均，未做市值/行业调整；R20 两段只有 48、78 天；成败按名单口径；没有登记影子（名额满）。
