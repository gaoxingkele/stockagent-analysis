# 布林 %b 与 CCI(14) 在 S20/R20 前 100 的深度验证（2026-10-16）

- **日期**: 2026-10-16
- **关联代码/实验**: `scripts/validate_two_factors.py`；产物 `output/experiments/two_factor_validation_20261016/{report.txt, checks.csv, variants.parquet}`；账本 T0110–T0112、N0037
- **证据等级**: reused_holdout，描述性。S1/S2、R20 两段都已用过，这两个因子又是在这些段上从 282 个里挑出来的；这里是追问「还剩多少」，不是验证。信号日 ≥ 2026-08-06 没有读。

## 对话

用户：你深度验证一下这两个选择出的因子，在 S20 R20 的 TOP100 里面进行加强筛选。

（「两个因子」我取上一轮表里并列的布林 %b(20) 和 CCI(14)；两者在 R20 池内秩相关 0.7～0.85。）

## 做法

池和成败口径同上一轮（名单口径 U15D10，成功 = 20 日内先涨 15%，先止损 = 先跌 10%，同日算失败）。每个池、每个时间段、每个因子做七类检查：

- **A 切法**：三分位、对半、五分位的高档减低档；每日秩相关（IC）；五档成功率是否单调。
- **B 参数**：%b 窗口 10/20/40，CCI 窗口 10/14/20/30。
- **C 中性化**：扣除 NATR 与流通市值后的残差分位；只在同行业内比；只在模型排名 1–50 或 51–100 内比。
- **D 稳定性**：分月、正差日占比、去掉一个月重算、10 日块自助法 95% 区间。
- **E 行情**：沪深 300 前 20 日涨幅为正 / 为负。
- **F 安慰剂**：同一天内把因子随机打乱 300 次，看观察到的差落在哪。
- **G 名单**：把因子当作额外筛选放进真正的名单（R20：r20_pred 前 20；S20：冻结合约名单），和原名单、以及「随机取三分之一」的对照同日配对比较。

脚本里重算的 %b、CCI 与上一轮因子表相关系数 1.0000。

## 结果

### R20 池：池内的区分力是真的，但加到名单上的增量很薄

高档（前三分之一）减低档的成功率差（百分点，t）：

| | 样本内 | 样本外 |
|---|---|---|
| %b 三分位 | +5.5（4.9） | +9.4（5.2） |
| %b 对半 / 五分位 | +5.1（4.8）/ +6.6（2.5） | +6.0（3.7）/ +11.0（5.1） |
| CCI 三分位 | +5.2（3.1） | +8.4（5.8） |
| 扣除 NATR 与市值后 %b / CCI | +6.7（7.7）/ +5.0（5.4） | +8.3（4.1）/ +8.3（4.6） |
| 同行业内 %b / CCI | **+1.3（0.6）/ +1.5（0.8）** | +6.9（4.9）/ +6.9（4.9） |
| 模型排名 1–50 内 %b / CCI | **+2.3（0.6）/ +2.5（0.7）** | +4.8（1.8）/ +5.2（2.6） |
| 模型排名 51–100 内 %b / CCI | +8.7（2.6）/ +7.2（2.3） | +11.3（4.1）/ +10.9（5.5） |
| 安慰剂 300 次中不小于观察值 | 0 | 0 |

站得住的：
1. 五档成功率基本单调（样本外 %b 26.2 → 30.7 → 32.0 → 35.4 → 37.1）；对半、五分位同号；打乱因子 300 次没有一次接近。
2. 去掉任一个月后 t 仍 ≥ 3.6（样本外）；10 日块自助 95% 区间样本内 [+3.0, +8.4]、样本外 [+6.7, +13.8] 个百分点；样本外上涨 / 下跌行情都成立（+11.3 / +6.3）。
3. 窗口不敏感：CCI 10～30 样本内 +5.3～5.8、样本外 +5.9～9.5；%b 10 日偏弱（+4.7 / +5.5）。
4. 样本外每笔收益差 +2.4（t 4.9）、先止损比例 −10 点，是真的收益改善；样本内每笔只有 +0.7（t 1.3），先止损比例没变（+1.8）。

站不住的：
1. **样本内的效应主要是行业**：同行业内比，样本内从 +5.5 降到 +1.3（t 0.6）。样本外同行业内仍有 +6.9（t 4.9）。也就是说样本内的因子差有一大半是「强势行业 vs 弱势行业」，选股能力只在样本外看得到。
2. **效应集中在模型排名靠后的部分**：排名 51–100 里 +7～11 点，排名 1–50 里样本内几乎为零（+2.3，t 0.6）。R20 最想用的前 20 名里，因子几乎没有额外区分力。
3. **名单层面增量很薄。** R20 前 20 本身比整个前 100 还差（样本内成功率 25.5% vs 28.4%，样本外 28.7% vs 32.1%）。把「前 100 里随机取三分之一再取前 20」放进来当对照，成功率就已比原名单高 +6.0（样本内）/ +3.2（样本外）。%b 高档三分之一再取前 20 是 +6.4（t 1.7）/ +6.2（t 2.8），也就是比随机对照多约 +0.4 / +3.0 点（相减得到，未单独检验）。CCI 同样（+6.4 / +5.6）。「排名与因子混合」样本内 +8.1（t 2.4），样本外只有 +3.6（t 1.8）。名单的每笔收益样本外 −1.62 → −0.04，仍不为正。

### S20 池：没有可用的加强筛选

| | S1 | S2 |
|---|---|---|
| %b 三分位 | +2.9（1.4），每笔 −0.42 | +4.2（1.7），每笔 +0.84 |
| CCI 三分位 | +3.0（1.6），每笔 −0.35 | +3.6（1.4），每笔 +0.65 |
| 同行业内 %b / CCI | +3.0 / +2.2（1.5 / 1.1） | **+0.7 / −0.2（0.4 / 0.1）** |
| 先止损比例差（%b） | **+7.6（t 3.7）** | −1.5（−0.8） |
| 行情上涨日 / 下跌日（%b） | +2.5 / +3.9 | **+7.6（3.8）/ +1.3（0.3）** |
| 把 %b 高档放进合约名单（NATR 截断之前） | 成功率 +5.4（t 1.9），随机对照 +2.3 | **+0.5（t 0.2），随机对照 −2.9** |

1. 池内两段 t 都不到 2；S1 正差日只有 55%，分月符号来回变。
2. S1 里高 %b 的先止损比例高 7.6 点（t 3.7），每笔收益反而更低，说明高 %b 的股票在 S20 池里同时更容易先涨 15% 也更容易先跌 10%，是波动代理；S2 同行业内全部归零。
3. S2 的效应只出现在沪深 300 前 20 日上涨的日子（+7.6，t 3.8；下跌日 +1.3），这是一个行情开关的线索，但是在已用窗口上拆出来的，只能当想法，不能当结论。
4. 放进合约名单没有增量：S2 +0.5（t 0.2）、S1 +5.4（t 1.9）都没有明显超过随机对照的波动。

### CCI(14) 对 %b

两者表现几乎一致（R20 池内、名单、中性化后差别都在 1 点以内）。CCI 在样本内每笔收益 t 稍高（2.0 vs 1.3），窗口 20/30 在 S20 略强，但没有新信息。

## 结论

- **R20 池内排序是真实信号**（安慰剂、分月、去月、行情分层都过），但**主要来自样本外 04-14 之后**，样本内一半以上是行业效应，且集中在模型排名 51–100，对前 20 名名单的增量接近随机取三分之一。
- **S20 不用**：加筛选既没有稳定的池内差，也没有名单增量；高 %b 在 S1 里更多先止损。
- 影子草稿 r20_bollinger_strength_v1 的主指标是池内成功率同日配对差，这个口径在保留窗口上很可能过；但这**不等于「前 20 名名单变好」**。如果要登记，建议把对照加上「随机取三分之一」，并加一条名单层面的次要指标。草稿我没有改，等你决定。
