## 一句话
在 stage1 候选池里，**直接截掉 natr14 最高的 40%，效果不输全市场下跌头、方向头和二者组合**（开发期三折中每折都是最好或并列最好）。所以反向减值的本质就是一个振幅上限，用一行规则就能实现。它在开发期稳定改善（每笔 +1.49%→+2.44%，14 个月中 11 个月更好），但在已消费的确认期基本持平甚至略差，因为它截掉了普涨月的大牛股。胜率本身则由止盈/止损规则决定：能买到 75%，代价是期望几乎为零。

## 为什么引入 (第一性原理)
R04、R05 的所有有效减值都表现为"纯跌降、震荡升、纯涨不动"，这很像一个振幅上限。按本仓纪律，任何学习式增益都要和最朴素的对照比：**如果一行波动率规则就能达到同样效果，模型就不应进入方案。**

## 核心思想 (讲直觉, 不堆公式)
**A. 学习式 vs 朴素（开发期三折，50% 抽样，池 = stage1 Top100，输出池的 20%）**

| 漏斗 | 纯涨 | 纯跌 | 震荡 | 每笔期望 | 胜率 |
|---|---:|---:|---:|---:|---:|
| F0 stage1 直接取 | 37.2 | 38.6 | 24.2 | +1.48 | 48.4 |
| **F1 截掉池内 natr 最高 40%** | **37.7** | **32.2** | 30.0 | **+2.38** | **53.1** |
| F2 截掉下跌头最差 40% | 37.2 | 33.0 | 29.8 | +2.13 | 51.6 |
| F3 方向头排序 | 37.6 | 33.8 | 28.7 | +2.12 | 51.1 |
| F4 F1 + 方向头 | 37.5 | 32.0 | 30.5 | +2.35 | 52.7 |

池内逐日相关：下跌头与 natr 相关 0.55，方向头与下跌头相关 −0.29。它们都在不同程度上读的是振幅。

**B. 全量宇宙、两个时期，Top20，U15/D10**

| 期 | 截掉比例 | 纯涨 | 纯跌 | 每笔期望 | 胜率 |
|---|---:|---:|---:|---:|---:|
| 开发 | 0 | 37.3 | 38.6 | +1.49 | 48.5 |
| 开发 | 40% | 38.8 | 32.9 | +2.44 | 53.0 |
| 确认（已消费，仅描述） | 0 | 43.5 | 48.7 | +1.34 | 46.8 |
| 确认 | 40% | 42.1 | 48.3 | +1.21 | 46.4 |

逐月看 11/14 个月更好，但 2026-08 从 +7.43% 掉到 +0.67%：普涨月里最极端的票正是涨得最多的。U 越大（目标越远），截振幅伤得越多；U 越小，截振幅越划算。**振幅上限的比例应和止盈目标联动，而不是一个常数。**

**C. 胜率—期望前沿（每笔，扣 0.3% 成本）**

| 止盈/止损 | Top20 胜率（开发/确认） | Top20 每笔期望 | 全市场胜率（开发/确认） |
|---|---|---|---|
| +5% / −15% | 75.5 / 75.0 | +0.73 / +0.05 | 71.0 / 63.3 |
| +8% / −15% | 65.4 / 65.7 | +1.08 / +0.35 | 63.0 / 53.4 |
| +10% / −15% | 60.3 / 60.5 | +1.21 / +0.46 | 59.9 / 49.3 |
| +15% / −10% | 48.5 / 46.8 | +1.49 / +1.34 | 53.6 / 39.2 |
| +30% / −15% | 46.5 / 45.8 | +1.88 / +2.93 | 53.2 / 39.2 |

"大概率会涨"可以通过规则直接买到：止盈 +5% / 止损 −15% 下 Top20 有四分之三赚钱。但期望几乎为零，一旦成本或滑点略高就转负。**胜率不是 alpha，期望才是。**stage1 的真实价值是确认期全市场每笔约 −1% 时，Top20 仍为正。

## 我们怎么吸纳 / 改造 —— 整体方案（三轴漏斗，参数不写死）

```
标签工厂    参数化首达面板 (U, D, M, H) ── 所有标签从这里切，不再冻结单一阈值
   │
轴 1 振幅下限（正向）  stage1：淘汰震荡/死票                          [已有，最强单信号]
   │
轴 2 振幅上限（反向）  池内截掉 natr 最高 c%，c 随 U 联动（U 小 c 大）   [一行规则；学习式反向头
   │                                                                      只有在新窗口赢过它时才启用]
轴 3 方向              只接受"新信息"：带时点的文本/公告/资金           [目前为空；验收指标 = 池内
   │                                                                      逐日方向 AUC、up/(up+down) 斜率]
日级        不预测日子；每日投入 1/N 资金分批、止损 −D 硬执行、         [R06]
            实际失败率在线监控（Gibbs–Candès 式收紧名单）作为护栏       [R08]
   │
输出        名单 + 当前规则 (U/D) 下的历史胜率/期望/实际 FDR 曲线，
            而不是"都会涨"的承诺
```

与用户原始设想的对应：
1. **"纯粹的上涨"** → 标签工厂里的 pure_up(U, M)；训练方向模型时只用纯涨对纯跌，震荡剔除（R04 证明比"震荡当负样本"好得多）。
2. **"纯粹的下跌，至少跌破容忍线"** → pure_down(D)，D 是参数；它在交易上就是止损线，是执行规则而不只是标签。
3. **"淘汰不涨不跌"** → 轴 1（stage1）已经做到，最高十分位的震荡从 76% 降到 24%/9%。
4. **"反向评分减值"** → 轴 2。它确实提高了每笔期望、降低了纯跌，但机制是振幅上限，用规则实现即可。
5. **"剩下的上涨概率就会高"** → 数据不支持：纯涨在所有漏斗里都卡在 37–39%。"剩下的"更多是震荡，不是纯涨。

🧩 三轴漏斗作为下一时期的预登记挑战者（stage1 + 振幅上限 c + 分批/止损）。❌ 学习式反向头作为必需组件。

## 移植提示 (必填)
任何"反向模型减值"都先和"按波动率截同样比例"比；输了就用规则。胜率一律连同期望一起报，并和"全市场同规则"比较。振幅上限的比例要按止盈目标联动，不要设成常数。不可移植：natr14 这个具体波动率定义、40% 这个比例，都需要在新市场重新扫描。
