# V12.31 选股规则（生产线 daily_top20）

> 当前生产线唯一在用的日频选股规则。2026-05-27 上线（`pump_ratio` 排序版）。
> 代码锚点：`src/stockagent_analysis/v12_scoring.py`（评分+铁律）、`daily_top20_XXXX.py`（排序+输出）。
> 适用：0526 / 0527 / 0601 / 0604 等所有 daily_top20 批次均走此规则。

---

## 一句话

**全市场评分 → V7c 6 铁律主推池 → 池内按 `ratio = P_up/(P_down+ε)` 排序 → 行业 cap 4 → Top N。**

本质 = **均值回归 / 抄底启动**策略（偏好近期回调股），动量单边行情会吃亏（见 §5）。

---

## 完整链路

### Step 0 · 全市场评分
- `V12Scorer.score_market(date)` 对全市场打分。
- **ST 源头排除**（数据加载即 filter，非事后）。
- 产出每股：`buy_r20_score / r20_pred / pump_score(P_up) / pump_down_score(P_down) / 4象限 / is_zombie / 行业动量rank` 等。

### Step 1 · V7c 主推池（6 铁律，全部 AND）→ `v7c_recommend == True`
代码：`v12_scoring.py::_apply_v7c_rules`（+ `_enrich_zombie` 第 6 条）。

| # | 铁律 | 条件 | 用意 |
|---|------|------|------|
| 1 | r20 相对排名 | `r20_pred` 当日 **top 5%** | 20 日收益预测模型 `r20_v16_long_nost`；v3 起从绝对阈值改相对排名（解决 OOS 空池漂移，覆盖 32%→100%） |
| 2 | 金字塔速度 | `pyr_velocity_20_60 < p35` | 资金未加速派发（低 35% 分位） |
| 3 | 双静默 | `|f1_neg1|<0.005 且 |f2_pos1|<0.005` | 事件因子中性 ±1%，排除异动 |
| 4 | 非僵尸 | `NOT is_zombie` | 排除横盘僵尸股（MA60 横盘度，第 6 铁律） |
| 5 | 行业动量过滤 | `industry_mom_60d_rank ≥ 0.10` | 排除 60 日动量**最差 10% 行业**（v4 加，防接行业下行飞刀；NaN 行业保留不误排） |

> 参数默认：`p_buy_top=0.05`、`industry_mom_excl=0.10`。

### Step 2 · 池内排序信号 = `ratio`
代码：`daily_top20_XXXX.py`
```python
ratio = pump_score / (pump_down_score + 0.01)      # P_up / (P_down + ε)
```
- `pump_score = P_up`：启动子 **`r5_pump_3way_lgbm_v3c`**（3 分类 softmax）预测"未来 5 日 `max_gain≥10% 且 max_dd≥−5%`"的概率。
- `pump_down_score = P_down`：同模型"下跌启动"概率。
- **ratio 越大 = 涨的决断度越高**。0527 从 `composite=P_up−0.5·P_down` 切到 `ratio`（OOS α +2.078→+2.236pp/月，灾难月 202602 翻盘）。

### Step 3 · 行业分散 + 截断
- 单行业 ≤ **4** 只（Top 20 内）。
- 按 ratio 降序取 **Top N**（默认 20；实际主推池常只有 10–15 只通过 6 铁律）。

## 5. 设计 DNA 与已知弱点（务必知道）

- **DNA = 抄底/均值回归**：r20 top + pyr_velocity 低 + 启动子 v3c 的 `past_r5≤+8%` + 整体"先下蹲后起跳"逆向风控 → **结构上偏好近期回调/超跌股**。所以每批 picks 的 `past_r5` 基本全为负。
- **已知弱点 = 动量单边行情**：当市场进入**动量延续**（强者恒强、小盘杀跌）时，它一路买"还在跌的回调股"，兑现为负选股。2026-05 底–06 初实盘即如此（0527/0601 批横截面分位跌到后 1/3）。
- **此弱点不可廉价修**（2026-06 实测，9–10 连否）：动量 regime 门控、止损、健康回调过滤 全部 walk-forward REJECT，且后两个反指。详见 `research/RESEARCH_LOG_2026H1_pump_ratio_regime.md` 与记忆 `project_three_rejects_meanreversion_meta_0603`。
- **正确应对**：当作风格 **tail risk** 管（仓位/分散），而非再加补丁；满 20 日（设计 horizon）才是有效性定论窗口。
