# S20 长期研究组合与 Harness 执行裁决

日期：2026-09-14。性质：研究执行计划，不是训练成绩或生产升级。沿用 `config/s20_v4_harness_plan.json`，不修改冻结目标、预算、阶段门槛和 R20/S20。本文汇总既有工作单并给出本轮放行顺序；新增诊断必须登记后才执行。

## 1. 决策摘要与当前证据

目标是在公开推荐覆盖率和资金使用率的前提下，提高安全上涨/盈利概率、减少危险误判。TopN 是上限而非配额，允许少选和空选，不能承诺每只不跌。股票形态不作先验排斥，不恢复行业四只上限，北交所单列数据准入、训练配置和评价。

本轮只读核对冻结配置、执行进度与 CLI report：H00 已接受，最新 H01 记录仍为 FAILED_VALIDITY；H02/H03 有诊断 intake，但正式验收未完成；H04–H10 正式阶段执行器尚未接通。共享预算、注册搜索、断点恢复、推理重算和简单联合模型已有合成集集成验证，不等于真实市场有效性。历史可得性、历史股票范围、公司行动及旧模型复现仍有缺口。

必须设置一个“停止扩建、先给研究结论”的检查点：数据范围裁决、一条真实基线闭环、前三项核心比较完成后，输出继续/无增益/权衡/证据不足，再决定高级路线。不能以不断增加组件替代真实验证。

## 2. 专家讨论与分歧裁决

本轮采用 SmartGoal：方法专家 A 独立提案；统计 C 与交易 B 由另一独立代理联合审阅；主代理承担工程 D、核对仓库和综合裁决。不声称四位独立代理同时参与。

| 问题 | 方法主张 | 反方意见 | 裁决实验 |
|---|---|---|---|
| 是否一定用联合四类 | 学习危险上涨与安全上涨的差别 | 直接安全事件可能更准，四类尾部样本更稀 | 同特征、同时间折比较直接安全事件、联合四类、条件三头 |
| 加大下跌惩罚是否足够 | 高机会高风险降低排名 | 可能只改变分数尺度、减少覆盖，未学习新信息 | 固定模型比较政策；普通输出按权重倾斜对照真正加权训练 |
| 拒选是否提高置信度 | 学习基础模型何时会错 | 可能只是 ATR 过滤或市场择时 | 控制机会分、ATR、流动性、市场状态；另报同日同 k 与全日历 |
| 高胜率是否实用 | 优先安全概率 | 少数大亏、不可成交可能吞噬小盈利 | 分开 O/P/T，检验同本金净收益、损失金额与尾部 |
| 要不要每日重训 | 适应状态变化 | 可能仅需要重新校准，或增加搜索噪声 | 固定、成熟反馈重校准、成熟反馈重训三路对照 |

旧锚风险层与不依赖旧锚的直接安全模型可分别研究。旧锚复现缺失不阻止独立诊断工程，但正式 H03 的完整基线验收不能因此跳过。

## 3. 三条目标轨道：不能相互冒充

- **O：机会。** D+1 入场参考后，窗口内安全触达 +15/+20，以及扩展 +25/+30/+35。沿用对应 O 版本的风险与先后顺序定义；安全达标后的回落不撤销已发生的 O 成功。
- **P：持有盈利。** 冻结主研究任务为 D+20 扣费终值盈利 U，危险事件 B5 为全窗口经济价值较入场成本跌破 -5%。四类为 A=U且非B5、B=U且B5、C=非U且非B5、D=非U且B5。这不是早期 O 标签中 A/B 的同义命名。B10 单独建端点。
- **T：交易兑现。** 实际成交、退出、成本、持仓与现金账本；不能以盘中最高价当卖出价。未成交、顺序不明、未成熟和无法退出分别保留。

基础选择顺序：数据/可执行性准入 → 风险硬门槛 → 排名 → TopN 上限。比较直接 pA 与效用 `pA - λpB - μpD - νpC`，其中 `μ > λ > ν >= 0`。效用不是概率；高上涨分不能抵消风险超限。概率权重和风险阈值只在各自内部段选择，不在测试集选。

## 4. 广泛路线库与启动条件

不是把下表全部训练；首轮按原 12 槽，扩展受原高级预算约束。每条路线必须写清 O 或 P 目标。

| 优先级/路线 | 可证伪假设与最小对照 | 停止或不启动条件 |
|---|---|---|
| 首轮：简单基线与直接安全事件 | 成熟历史频率、逻辑回归、浅树、ATR/流动性以及旧版参照；判断是否已有可预测信息 | 标签/来源有效性未通过，不作正式成绩 |
| 首轮：旧机会锚 + 风险层 | 严格 OOF 机会分相近时，学习风险胜过简单过滤 | 仅少选、仅低波动或锚泄漏，不扩容 |
| 首轮：联合与条件任务 | 直接 pA、四类、条件三头；独立双头仅作合法边际对照，不相乘冒充联合概率 | 复杂模型不胜直接 pA，保留简单模型 |
| 首轮：成本敏感/难负例 | 训练内部 OOF 挖掘高分危险样本；普通训练、输出倾斜、加权训练同预算比较 | 增益可由输出重标度复制，不宣称学到新信息；自然分布校准不重采样 |
| 必做：校准与拒选 | 检查入选股票而非仅全市场概率；简单风险门 vs 学习误判拒绝器 | 同覆盖无增益或入选校准不成立，保留 rank-only 结论 |
| 条件：多阈值/序数任务 | 共享 +15…+35 目标，约束高目标触达概率不高于低目标 | 仅一致性好看、核心目标无改善；高目标事件不足 |
| 条件：首次触达/竞争事件 | 模型利用到达目标或风险界限的先后与等待时间 | 日线同日顺序不明不得强填；早反馈另登记删失任务 |
| 条件：风险严重度 | 同风险概率仍有不同损失金额；经验分组对照条件分位数/分布模型 | 只降低 MAE 未改善交易尾部，或一段危机决定全部结论 |
| 条件：不确定性拒选 | 训练支持度/模型分歧在机会、风险、ATR 之外提供信息 | 仅重复风险分；确定性换 seed 没有新增证据 |
| 条件：状态稳健与漂移 | 市场状态可提前识别残差；固定 vs 重校准 vs 滚动/衰减，再考虑元适应 | 重训不胜重校准，关闭复杂适应；严格一致成熟反馈时钟 |
| 较晚：MLP/TCN/序列 Transformer | 时间顺序提供摘要因子没有的信息 | 同窗口摘要树、时间打乱后效果相同，不扩展序列模型 |
| 较晚：市场关系/图 | 事前关系在市场/行业公共因子之外提供增量 | 无图或随机边同样好；事后行业归属/未来相关性泄漏 |
| 较晚：成熟历史检索/表格基础模型 | 历史相似状态或迁移表示提升低样本稳定性 | 检索命中未成熟未来、相邻 episode 重复；不胜近邻/浅树 |
| 最后：联合路径生成 | 联合路径分布增加尾部或顺序辨识 | 模拟校准失败；合成路径不能增加独立市场证据量 |
| T 单列：延迟入场与共同亏损 | 即刻、固定延迟、每日新评分触发；另测组合共同暴露 | 事后最低点入场才有效；保留原失败、未触发、错失机会，不恢复行业硬帽 |

强化学习及模型、退出、仓位全联合搜索暂缓：自由度高，先证明固定政策下信号有效。

## 5. 核心差异特征：按信息增量验证“正交”

候选组：收益路径与反转/延续、波动及尾部、量价与流动性、市场广度/状态、事前行业与相对强弱、基本面/事件（仅有可靠发布日期者）、旧模型 OOF 分数、训练支持度。

每组做“基础组 → 加入组 → 移除组 → 匹配噪声组”消融；控制机会分、ATR、流动性、市场状态，报告逐折增量、入选错误变化与成本后表现。所有变换和残差化只用过去训练段拟合。相关性低、SHAP 大或单次重要性靠前都不能单独证明独立信息；没有增量就删组，不给形态设主观准入条件。

## 8. 如何判断真的提升

先用历史开发折比较，不再把已经看过的历史称作独立测试。主要报告安全盈利/触达精度、B5/B10、损失金额、入选校准、覆盖/空选、最差月、成本后同本金结果；允许个别月份差，但检查优势是否只来自一个月份或行情。

同日按候选实际通过数匹配基准用于归因，不是部署时强行补足 N 的规则。未知结果保留上下界，不当负例或删掉；该上下界不等于统计置信区间。

市场证据按配对交易日期块与 episode 处理，原协议块长 20/40/60 做敏感性分析，不把同股相邻日或随机种子当独立市场样本。原 G3 不变：未来同覆盖安全盈利差的 95% 下界 > 0，风险10差的 95% 上界 < 0。60 个成熟信号日只是首次查看入口，不保证功效；稀有事件不足则证据不足。G4/G5 是后续挑战，不承诺达到，也不替换 G3。

## 9. 文献工作包

研究范围按过去五年滚动筛选，逐篇保存任务、数据、时间切分、延迟反馈、成本、理论假设、作者代码版本和最小复现实验。每条路线先复现最小对照再引入论文方法，不能用论文名气替代本地验证。本轮仅核对以下原始来源，不是五年系统综述，也未运行 mylib：

- [CCL-SC，ICML 2024](https://proceedings.mlr.press/v235/wu24s.html)：选择性分类与表示学习；原图像实验不是股票证据。可提案比较学习拒绝与简单拒绝。
- [Conformal Risk Control，ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/f3549ef9b5ff520a7e41ff3cc306ab2b-Abstract-Conference.html)：风险校准方法来源；需要核验适用假设，不能直接推导非平稳 TopN 逐股不亏保证。
- [DoubleAdapt，2023](https://arxiv.org/abs/2306.09862)：股票预测增量适应候选；在本任务中必须对照相同成熟反馈时钟下的简单滚动与重校准。
