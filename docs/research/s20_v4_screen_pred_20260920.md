# 因果沉默筛选与指定 +15% 上涨预测（2026-09-20）

状态：诊断完成。**非正式 H04，未授权正式训练，不进生产。** 排序仍冻结 multinomial_base。沉默 **不是数据质检**：行情路径有效，只是 20 日没有 S20 要的波动。

## 筛选与目标

主档 **+15% 可提前走 / −10% 路径**。指定上涨 = T+1 之后触及 +15% 止盈（不是到期小涨）。沉默 = 窗口最高涨幅 **< 8%** 且 **未破 −10%**。当天未走完的最高价不决定当天池子。

入池只用 `label_available_at < prediction_at` 的成熟实体冷却，以及滚动校准的 P(沉默)、独立 P(B10)。高上涨分不能抵消 −10% 门。

π0 = Top20、惩罚效用、不开门。挑战者须在回放段提高指定 +15% 命中率、配对 −10% 不差于 π0、相对 π0 的 20×日覆盖 ≥ 0.3，再在外层同样确认。外层数字只确认，不改 8% / +15% / τ。
