## 2. 当前标签的准确条件

信号日 D，市场日历 D+1 开盘买入，D+20 收盘为到期；买入当天不能止盈卖出，最早 D+2。主档价格涨幅 +15% / 路径风险 −10%，次档 +25%/−15% 只报告不选策略。

`take_profit.first_take_profit`：首个可卖日 high ≥ 入场价×1.15 时按目标价退出，否则按到期 close 退出。净收益 = 卖出价×(1−0.0015)/(入场价×(1+0.001))−1；净收益严格 >0 才算盈利，零收益归不盈利。

| 配对标签 | 净收益 | 从买入到退出的风险事件 |
|---|---|---|
| A 安全盈利 | >0 | 未发生 |
| B 危险盈利 | >0 | 发生 |
| C 安全不盈利 | ≤0 | 未发生 |
| D 危险不盈利 | ≤0 | 发生 |

- A∪B 是盈利，不等于指定 +15%。指定上涨标签是 `exit == take_profit`；此前发生风险后再止盈也可 hit15=true，因此它与风险并不互斥。
- 当前风险条件是 low < 入场价×1.001×0.90，即相对原始入场价严格低于 −9.91%；风险不是峰值到谷值最大回撤，也没有触发自动止损卖出。`breached_drawdown` 辅助函数却按原始入场价的 MAE <−10% 判断，不能混用两者。
- +15% 是价格目标，按现费用净收益约 +14.71%，不能描述成扣费赚 15%。
- 沉默：完整窗口 max(high)/入场价−1 <8%，且未发生配对风险。它横跨 A/C，不是第五个互斥类，也不是数据无效。已知沉默不得用于事前删除当前候选。
- 同日同时触及止盈和风险线：日线无法判顺序，函数返回 ambiguous_same_day，盈利及四类未知，保留上下界。缺失/无法退出另列 unresolved。完整推荐账本不应删掉这些记录来提高指标。
- 当前 screen 脚本在排序前 dropna 删除未知标签；panel 构造也使用未来窗口可用性筛样。这是诊断样本范围的限制，新协议应先建事前候选账本，未知仅退出相应监督损失，不退出推荐覆盖和未知统计。

## 3. 重训目标与新标签提案

主目标：提高指定 +15% 的可实现命中率，配对风险率不高于同期 π0，覆盖至少为 π0 的 20×信号日的 30%。不再以 A∪B 上升替代目标达成。

保留上述 A/B/C/D 作为历史兼容报告。用户最新决定：主分类采用 A/B/C/D/S 五类，仅将原 A 中最高涨幅 <8% 的沉默盈利移入 S；B/C/D 保持原定义。新 A 不等于 +15% 达标，实际盈利改计 A+B+S，风险仍计 B+D。五类模型与独立风险头是后续主对照，不能将旧四类预测冒充五类概率。

以下两事件联合四类降为辅助诊断，不替代用户指定的 ABCDS 主分类：

| 新目标类 | H：可卖时段 +15% 止盈 | R：退出前配对风险 |
|---|---|---|
| U 安全达标 | 1 | 0 |
| V 带风险达标 | 1 | 1 |
| W 未达标且安全 | 0 | 0 |
| X 未达标且有风险 | 0 | 1 |

指定 +15% 的 H 标签另行预测/统计，不能由 ABCDS 中的 A 直接替代；另外训练独立 P(R) 用于硬门。S 作为主分类标签保留，C 中的沉默标记作为辅助诊断，首轮不删除沉默、不增加沉默门搜索。未知标签保留掩码，不强转 bool。

为保持可比性，第一版沿用历史含成本风险线并明确命名。精确原始价格 −10% 另做预登记敏感性重标；若决定迁移，须更换标签版本并在同一批样本同时重评 π0，不能沿用旧 5.9% 作为新定义下的基线。止盈执行与同日歧义处理同样版本化。

## 4. 有界执行顺序

1. **标签与账本审计，无拟合。** 固定数据、模型、标签与切分哈希；复算 π0 的 43/320、19/320 和类计数；逐项测试 T+1、等号边界、费用、先风险后止盈、同日双触、停牌/涨跌停/公司行动、缺失与标签成熟时间。输出新旧标签迁移矩阵、未知比例、候选流失原因及反事实覆盖对照。不得用新的文件时间戳补造历史可得性。
2. **先完成 L1 可分性诊断。** 使用已有冻结预测，在开发段联合查看上涨分×独立风险分的分桶、风险门通过后的机会召回、U/V/W/X 与沉默的分布。如果可分，只登记小规模选择规则实验；如果既有分数无法区分安全上涨和危险上涨，再进入重训。现有纯 P(+15%) 排序失败说明目标冲突，不足以直接证明需要复杂模型。
3. **小模型目标对照。** 保留 π0 和既有配对重训结果；新增成熟频率基线、ABCDS 五类多项逻辑回归、H/R 二元逻辑回归双头。首先让训练器/校准器/模型卡显式支持 ABCDS，并检查旧的 A+B 盈利统计改为 A+B+S；不能将五类标签直接传给硬编码 ABCD 的旧训练器。固定现有五项价量特征（20 日收益、均线距离、ATR%、收益波动、量比），不恢复已否决的 Wilder RSI。先比较目标变更效应，再考虑特征变更。
4. **校准与选择。** 概率校准只用时间上严格成熟的样本外预测；避免将训练集拟合分混入校准。沿用滚动 Platt 的事前规则，但样本不足/单类时必须标注未校准，不能把 raw fallback 称为校准概率并套绝对概率门。风险门先行，再按新 P(A) 或 P(H) 排序；前者是非沉默安全盈利，后者是指定达标，二者必须分别验收。不合格可空缺，高上涨分不能抵消风险拒绝。
5. **一次确认与裁决。** 开发段冻结候选后在未参与开发的窗口确认；不达标保留 π0。正式训练仍需已验收数据范围及正式阶段前置条件，诊断改进不能自动取得 H04 或生产资格。

首轮预算提案：3 个时间前推折；逻辑回归正则只试 0.1/1/10；五类头与双头合计每折 9 次基础分类器拟合，合计 27 次，另单列频率基线和校准次数。选择层仅试新 P(A)、P(H) 两种排序与最多 4 个开发段冻结风险阈值，π0 固定纳入。保留至多 2 个挑战者加 π0。此预算是待登记提案，不修改现有冻结运行协议。树模型/序列模型不在本轮预算内。
