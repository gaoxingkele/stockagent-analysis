# 20 日窗口内可以提前止盈（2026-09-18）

状态：评价规则补丁。P 轨「拿满 20 日」仍保留作对照，**不再当作唯一成功定义**。非正式 H04。

## 规则（预先登记，不在外层搜参）

买入 D+1 开盘后：

- T+1：买入当日不能卖。
- 之后一旦最高价触及目标，按目标价减参考卖出费用离场；不必拿到 D+20。
- 从未触及目标则落到 D+20 收盘（原来的持有到期）。
- 同日既触及止盈又跌破 −5%：保留在事前集合，记上下界，不按未来路径丢掉。
- 止盈阈值预先取 5% / 10% / 15% / 20%。10% 作主报告档，不是事后挑最漂亮的一档。

这与旧 O 轨「曾经涨过 20%」不同：这里是**可执行离场**，T+1 约束，成交按目标价而非当日最高价。
