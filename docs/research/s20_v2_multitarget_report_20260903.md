# S20-v2 五目标训练报告（2026-09-03）

## 结论

S20-v2 的标签与训练管线已经完成，但当前模型未达到晋级门槛，状态固定为
`offline_completed_not_shadow_eligible`。不运行全市场确认，不启动 shadow，不修改 R20、网页、池子或每日 21:00 任务。

S20-20 在 145 个测试交易日的每日 Top20 命中率为 21.17%，全体基准率为 16.03%，lift 为 1.321。该结果说明存在一定排序信息，但不能称为稳定的高置信度概率。

## 冻结标签

评分时点为 D 收盘，D+1 开盘买入，观察 D+1 至 D+20。五个独立目标及目标前最大允许回撤分别为：

| 目标 | 最大允许回撤 |
|---:|---:|
| +15% | -8% |
| +20% | -10% |
| +25% | -12% |
| +30% | -12% |
| +35% | -12% |

正样本要求目标首次命中前未跌破对应风险线，并且目标命中日之后至 D+20 的最低价不低于 D+1 开盘价。负样本分为 N1（未达标且未止损）、N2（达标前先止损）和 N3（达标后跌破入场价）。目标命中日内同时跨越上下界、且此前未明确止损的样本标为 ambiguous 并排除损失函数。

全量生成 3,215,747 行、5,300 只沪深股票、零重复；信号日期为 2024-01-02 至 2026-08-05，行情覆盖至 2026-09-02。五目标正样本率依次为 19.20%、15.86%、12.62%、9.61%、7.29%。D+1 入场价与旧标签重叠 2,441,863 行完全一致。

## 训练设计

- 50% 固定哈希样本，抽样种子固定为旧 B0 的 `20260830`，保证逐行公平对照。
- 176 个既有因子，五个独立二分类 LightGBM；每个目标使用三个模型种子取均值。
- 每目标另训四分类原因模型，输出 positive/N1/N2/N3 概率，但不混入主评分。
- 三折严格时序 walk-forward。fit、tune、calibration 的 `horizon_end_date` 必须早于下一阶段起点，杜绝 20 日标签尚未成熟时被训练读取。
- 排序看每日 Precision@10/20/50 和 lift；概率看逐折 Brier Skill、ECE 和选股尾部误差。

## 诊断与下一实验边界

当前失败主要是跨阶段漂移，不是样本量不足。45 个二分类模型中有 17 个在第 1 至 3 轮即早停；wf2 能学习较深，而 wf1/wf3 多数很早停止。静态 Platt 把前一阶段基准率带入下一阶段，排序不变但概率可靠性变差。

本次测试结果已经被查看，后续不得在同一测试期上反复调参后宣称晋级。下一候选应预先冻结后，只在新的未触碰时期确认：

1. 将每日截面百分位/标准分作为主输入，降低跨市场阶段尺度漂移。
2. 使用按交易日分组的 LambdaRank 学习 Top-K 排序，再用独立概率头解释达标概率。
3. 以仅含已成熟标签的滚动基准率或在线校准替代固定月份 Platt。
4. 更新因子到 2026-08-05，并把 2026-01-27 之后作为一次性新 holdout；在冻结下一版前不得查看其标签结果。
