# R20-P v2 概率指数探索报告（2026-08-30）

## 结论

新版方向成立，但暂不进入网页影子运行。现存 `r20_pred`、`buy_r20_score`、池 A v1
以及每日 21:00 更新任务继续作为唯一生产版本。本实验没有修改任何生产别名、池 A
准入逻辑或计划任务。

R20-P v2 的目标不是替代收益预测值，而是给出可解释的绝对概率：

```text
P15_safe = P(未来20日内最高涨幅 >= 15% AND 最大不利幅度 >= -15%)
P20_safe = P(未来20日内最高涨幅 >= 20% AND 最大不利幅度 >= -15%)
P25_safe = P(未来20日内最高涨幅 >= 25% AND 最大不利幅度 >= -15%)
R20-P    = 100 * P25_safe
```

三个概率强制满足 `P15_safe >= P20_safe >= P25_safe`。形态、趋势、行业和市场状态
只作为预测信息，不作为硬性准入条件；没有行业 cap 或 TopN。

## 数据与防泄漏边界

- 原始标签：2,514,764 条；本次确认性运行固定哈希抽取 50%。
- 有效实验样本：1,200,265 条、4,882 只沪深股票。
- 日期：2024-01-02 至 2026-01-26。
- 当前名称含 ST 的 20,624 行被排除；北交所不进入本实验市场域。
- 标签使用下一交易日开盘作为入场价，未来20个交易日最高价/最低价/第20日收盘价计算。
- `r20_close <= max_gain_20` 等逻辑约束已逐行验证，无重复股票日期键。
- 每折严格划分拟合、调参、概率校准和测试四段，后段数据不回流前段。

三折测试区间分别为：

1. 2025-03-01 至 2025-04-30；
2. 2025-07-01 至 2025-08-31；
3. 2025-11-01 至 2026-01-26。

## 候选模型

实验比较了：

- 旧式 R20 回归输出再做概率校准；
- 四级有序联合模型（未达15、达15、达20、达25）；
- P15/P20/P25 三个直接二分类模型；
- isotonic 与 Platt 两种独立月份校准；
- 固定 50/50 集成：有序模型 isotonic + 直接二分类 Platt。

按“所有测试折 Brier Skill 为正优先，再比较总体 Brier Skill 与 PR-AUC”的预设规则，
最终候选为固定 50/50 集成。旧式 R20 回归校准基线整体为负 Brier Skill，证明相对
R20 排名不能直接改刻度后冒充达标概率。

## 完全留出测试结果

测试集共 350,608 条：

| 目标 | 基础发生率 | Brier Skill | ECE | ROC-AUC | PR-AUC | 最高十分位命中率 |
|---|---:|---:|---:|---:|---:|---:|
| P15_safe | 27.48% | +2.46% | 1.88% | 0.629 | 0.353 | 37.97% |
| P20_safe | 18.68% | +2.41% | 1.50% | 0.631 | 0.257 | 29.24% |
| P25_safe | 12.94% | +2.20% | 1.28% | 0.640 | 0.191 | 22.52% |

P25 最高十分位相对基础发生率提升约 1.74 倍。三个测试折的 P25 Brier Skill 分别为
`+1.03% / +1.84% / +2.26%`，没有任何一折退化为负值。

## 为什么仍不进入影子运行

总体 P25 十分位在允许1个百分点统计波动时保持单调，但最早测试折没有做到逐档单调。
这说明模型已经能提供有用概率信息，却仍存在市场阶段漂移；目前把它放上网页容易让用户
把实验概率当作生产承诺。

因此当前状态固定为：

```text
offline_confirmed_not_shadow_eligible
```

下一研究动作是扩大时间覆盖、改进跨市场阶段校准，并在所有 walk-forward 折都通过概率
分档稳定性后再申请影子接入。影子期也至少需要40个有效交易日，期间池 A v1 不变。
