## 2. 三个量级事实（决定了下一步的形态）

### 2.1 折预算与现有样本相差一个数量级

诊断样本实测：**77 个信号日 × 741 只股票**（全部 `code % 7 == 0`），2024-06-05～2025-12-25，55,530 行，每日 705–733 行。类别重算与计划表逐项吻合：A 15,098 / B 1,075 / C 9,981 / D 13,690 / S 15,685，另 1 条同日双触未知。

计划默认每折 `fit ≥120` 且 `tune/calibration/policy 各 ≥40`，即单折 ≥240 个信号日、3 折 ≥480～720 个信号日。实际只有 77 天。**3 折不可行；2 折同样不可行。** 在 77 天上只能构造单折（约 `fit 25 / tune 8 / calibration 8 / policy 8`），且必须显式标注证据不足。折预算必须由"获批范围的信号日数"反推，不能先写死 120。

### 2.2 原始日线缓存有 662 个交易日，但"可得时间"只从 2026-08-06 起成立

`output/tushare_cache/daily/`：662 个文件，2024-01-02～2026-09-23，5,556 个代码，字段 `ts_code/trade_date/open/high/low/close/pre_close/change/pct_chg/vol/amount`。写入时间证据：

- 2024-01-02～2026-07-01 的全部文件 mtime 集中在 **2026-07-01 17:48–18:02**，属一次性回填。
- 2026 年 177 个文件中只有 **27 个** 的文件名日期与 mtime 同日。
- 稳定的当日落盘从 **2026-08-06** 起（其后为 21:2x，与生产 21:00 任务一致）。

因此：**可举证的"当日可得"窗口约为 2026-08-06 起、约 33 个交易日**；再扣掉最后 20 个交易日的标签成熟期，可用信号日更少。按每日信号与 120 日下限，前瞻路线最早约 **2027-02 达到 120 天、2027-03 全部成熟**。若接受"另行授权的回溯假设"，662 天立刻可用。

### 2.3 pA ≥ 0.50 是结构性清空阈值（本次复现）

47 训练日 / 30 测试日、仅用计划固定 5 特征、多项逻辑回归 C=1：

| 指标 | 实测 |
|---|---:|
| pA 分位 p50 / p90 / p95 / p99 / max | 0.229 / 0.347 / 0.378 / 0.430 / 0.568 |
| `argmax=A 且 pA≥0.50` 名额 | 9 行 / 21,794（**0.30 名额/日**） |
| 纯 `argmax=A` 名额 | 2,635 行（87.8 股/日） |
| 入围线所需名额（20×30%） | **6 名额/日** |
| corr(pA, path_risk) | **+0.305** |
| argmax=A 子集真实风险率 vs 全体 | 0.302 vs 0.164 |

差值 20 倍。0.50 应改写为**预登记分位规则**（校准段 pA 的 90/95/99 分位，本样本约 0.35/0.38/0.43），或改为"`argmax=A` + 风险门 + 按 pA 排序"。纯 `argmax=A` 的供给充足，说明问题只在绝对阈值而不在排序。

## 5. 开跑前必须冻结的预登记清单

1. pA 门：分位规则与数值（替换固定 0.50）。
2. 风险门：联合 `pB+pD` 与独立风险头用同一冻结阈值（q25/50/75/100 分位）。
3. 统一合格序列：`argmax=A` → 双风险门 → pA 降序 / 风险升序 / 代码破同分，Top20/30/40/50 为同一序列前缀。
4. 必报指标：**门后剩余供给**、随机 Top20 对照、同日候选 A 基数、第 21–50 名实际 A 率与风险率。
5. 可比性口径：`A 率不下降` 必须写明是对**同门同池**基线比较；预测主类 B/D 入选为零与风险门高度冗余，不得当独立安全证据。
6. 版本隔离：新目录与契约哈希；`silent` 列（M<8% 且 R=0，15,685）与 `v4-abcds-a-only-v1` 的 S（原 A 且 M<8%，5,996）必须有一条断言二者计数不同的测试。
7. 边界测试：`hit15=True` 且 `max_gain` 恰为 0.15；8% 等号；0.079–0.081 敏感带单独统计。
