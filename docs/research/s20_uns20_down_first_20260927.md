# unS20 下跌优先标签重训（2026-09-27）

状态：数据集和模型已重建。**不是下跌榜晋级，不能拿去踢 S20 TopN。** 确认窗 2026-01-27～08-05 和保留窗 2026-08-06 之后都没有用。

## 标签

不再用 `positive20 == 0`。新标签 `down_first20`：T+1 开盘进场，20 个交易日内 **−10% 下轨先于 +20%**。同一天两边都摸到记歧义，不进训练。后来才跌破、但 +20% 先到的，不算这次下跌事件（另记 `down_any20`）。

全市场 2,459,120 行、5,255 只，信号日 2024-01-02～2025-12-25（窗口必须在 2026-01-26 前走完）。已解析样本里先跌破占 **31.6%**。原因：闷住没破线 1,203,932，先跌破 774,976，先达标 407,676，达标后跌回入场价 67,797，歧义 4,739。

## 训练

50% 抽样，与 S20-v2 相同的种子和三段净化走样。特征是 stage1 那套可移植因子（166 列）。三个种子的 LightGBM 二分类，校准段做 Platt。产物在 `output/experiments/s20_uns20_20260927/`。
