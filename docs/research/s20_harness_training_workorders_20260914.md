# S20 长计划：训练与验证执行工作单

## 本轮长计划交付：执行边界与研究决策树

本轮只读 `python -m research.s20_harness.cli report`：H00 已验收；H01 最近记录仍为 FAILED_VALIDITY；H02/H03 只有诊断 intake，正式验收未实现；H04–H10 阶段执行器未实现。以下为实施计划，不表示已训练或已有性能提升，不修改冻结协议、生产 R20/S20、网页或 21:00 任务。

### 首要决策

不要把“推荐尽量都涨”简化成单一准确率最大化。研究输出必须同时包含安全事件概率、危险路径概率、排序效用、推荐覆盖和可兑现收益。风险门槛先于排序；允许少荐或空选，但空选不是成功样本。概率与惩罚后的效用分分栏展示。O 的安全触达成功与 P 的固定期限盈利不互相替换，T 检验兑现。

按以下顺序释放实验：

1. 固定同一批完整候选、日期与 OOF 机会锚，对比原排序、简单 ATR/流动性门与学习风险门；若收益来自简单过滤，保留简单方案，不升级模型。
2. 对比直接安全事件、联合四类、条件分解与独立双头；独立上涨概率和风险概率不得相乘冒充联合安全概率。
3. 固定政策比较普通损失与成本敏感损失；固定模型比较直接安全概率排序、风险门后排序、风险门后效用排序，避免同时改变训练和政策无法归因。
4. 错误集中在目标边界，启用多阈值；集中在先后顺序，启用危险率/多状态；集中在少数深亏，启用损失严重度；集中在持续漂移，比较滚动与自适应。只使用内部开发证据触发。
5. 摘要特征不足且顺序有增量才启用 TCN/Transformer；公共因素控制后关系仍有增量才启用图；检索只访问已经成熟的历史片段。生成路径、强化学习与联合交易优化不作为第一轮必做项。

### Harness 每项工作的完成定义

每项依次交付：可证伪假设和输入合同 → 实现与泄漏/中断/篡改失败注入 → 合成小链 → 数据准入后的真实小链 → 有界批量 → 重算与科学结论。组件测试通过不能代替阶段验收。

必备工单字段：experiment_id、track、hypothesis、control_ids、data/label/feature/split/code/environment 哈希、训练/调参/校准/政策/外层边界、实际随机种子及其作用、完整允许组合、模型级与底层 fits、校准和政策评估预算、资源上限、产物清单、验收、停止、恢复策略。确定性模型仅换 seed 不算新增独立实验证据；同股相邻日重复推荐也不算独立样本。

近期四项实施优先级：

- 数据范围裁决：有限批次列明历史可得性、身份、日历、公司行动缺口；无法证明的历史只能诊断，不回填时间戳；未来采集另列方案。
- 最小真实基线：完成 H02/H03 正式准入和旧版复现归因，保留全候选、未知及未成交，先跑一条可重算的小模型链。
- 比赛准备：补齐 configuration/fold/seed 身份与真实参数作用、配置级汇总、同覆盖对照、完整预算；不能从单次任务表现直接自动选冠军。
- 科学验证：冻结 power_plan、review_schedule、最小实用效应、具体日期拆分；对 O/P/T 建迁移与损耗归因。未知结果上下界不等于统计置信区间。

预算继续沿用首轮 12 配置×2 种子×3 折、最多 72 次模型级 fit；旧锚重训及 OOF 不免费，多头底层 fits 另计。最多三名候选补到总计三种子；校准/政策组合显式枚举，不做隐含全组合搜索。高级最多两个家族、六个配置，触发不成立就跳过。

验证同时报告：O 安全 +15/+20 触达；P 净盈利、安全盈利、B5/B8/B10 与损失严重度；T 同本金净收益/NAV、成本、成交、现金占用；各自的月度、覆盖与未知结果。按日期块及持仓 episode 处理依赖，不按股票行数计算独立样本。原 G3 未来同覆盖安全盈利差 95% 下界 >0、风险10差 95% 上界 <0 不变；60 个成熟信号日只是入口，不是足够证据承诺。允许 NO_GAIN、TRADEOFF、INSUFFICIENT_EVIDENCE，无合格候选时不替换 R20。

本轮核对的论文启发：[Conformal Risk Control (2024)](https://proceedings.iclr.cc/paper_files/paper/2024/hash/f3549ef9b5ff520a7e41ff3cc306ab2b-Abstract-Conference.html) 与 [Non-Exchangeable Conformal Risk Control (2024)](https://proceedings.iclr.cc/paper_files/paper/2024/hash/de04896f011beff76c91e094f72727f4-Abstract-Conference.html) 可用于风险校准候选，不能直接保证每只股票不亏；[DoubleAdapt (2023)](https://arxiv.org/abs/2306.09862) 可用于漂移适应候选，需与相同成熟反馈延迟的滚动基准比较。本轮不是五年系统综述，也未调用 mylib 检索实现。

## 决策与分歧

目标是在有意义的推荐覆盖下提高安全上涨/盈利概率、降低下跌风险，不承诺逐只不跌。R20、旧 S20 保留为有效参考。机会触达 O、固定期限安全盈利 P、真实执行 T 分轨，不能用 D+20 终值替换用户认可的安全 +15%/+20% 触达成功，也不能用盘中最高价充当卖出成交。

方法专家主张先做旧锚风险层、直接安全盈利/联合四类、条件风险，之后按残余错误启动多阈值和路径模型。量化反方要求同时报告盈利金额，防止效用排序偏好低波动小亏；统计反方要求完整组合预算、入选后校准与有效日期块，防止选择偏差。工程收敛：直接 pA、风险硬门槛和加权效用都作为有限竞争政策，而不是先认定惩罚越大越好。

P 轨四类是净盈利 U 与全窗口相对入场经济价值曾低于 -5% 的 B5 的联合事件：A=U且非B5，B=U且B5，C=非U且非B5，D=非U且B5。不同于早期 O 轨 A/B 命名。候选效用为 `pA-lambda*pB-mu*pD-nu*pC`，`mu>lambda>nu>=0`；它不是概率。必须另设不可由上涨高分抵消的风险准入，并对照直接 pA。四类会丢失收益金额和尾部深度信息，须并列评估。

### 立即补齐的三项可失败合同

1. **RISK-INCREMENT**：固定 OOF 机会锚、完整候选和日期，比较原排序、ATR/流动性过滤、学习风险门。学习风险与简单过滤必须在相同政策数量预算下竞争；过滤不覆盖原分数，不删除原候选。按政策实际当日入选数匹配基准，另报全日历与资金利用；机会分、ATR、流动性、市场状态的分层规则仅由内部数据确定。产物 `risk_increment_contract.json`、`conditional_increment.csv`。若条件匹配后优势消失，结论为简单过滤贡献，不称学习到额外风险信息。事后同 k 是归因诊断，不伪装成可部署门槛。
2. **POWER-PLAN**：在冻结前，用开发期完整日期块进行规划性模拟；覆盖基准风险率、最小有意义改善和依赖强度，检查零效应误判率，输出成熟日/episode/坏事件数量需求与固定查看安排。产物 `power_plan.json`、`power_sensitivity.csv`。实际参数必须由开发证据和可接受误差确定，不在此凭空给样本量。若需求不可承受，结论为暂无法验证；不改风险10终点，不事后放宽 G3。
3. **O-P-T-BRIDGE**：对同一批冻结推荐建立机会触达→固定持有→可执行收益迁移表，拆出未成交、重复持仓、现金占用、跳空、不能退出和成本侵蚀。产物 `opt_transition.csv`、`execution_loss_attribution.csv`。机会 O 提升而 P/T 未提升，只称机会识别改善。延迟入场、止盈另注册，不追溯改写原推荐失败。

| 滚动 / 增量适应 | 跨折存在持续漂移 | 简单滚动、时间衰减；统一完整 20 日反馈延迟，不能先喂早到负例 |

| 市场关系 / 图 | 控制公共因素后还有关系残差 | 无图、随机边、事前图；不能用当前关系回填历史 |
| 成熟历史检索 | 有足够不同历史行情邻居 | 去同行情重复、树基准、有效邻居数；禁止检索未成熟结果 |
| 表格基础模型 | 小规模资源探针可行 | 同历史窗同采样 GBDT/MLP；单列预训练数据透明性风险 |
| Copula / 联合路径生成 | 简单尾部与路径方法不足，最后启动 | 简单路径重采样、分位数、独立边际；合成路径不增加真实验证样本数 |
| 延迟入场 / 退出 / 组合 | 预测固定后单独政策实验 | 即刻、固定延迟、评分触发；新决策重新计时，保留原失败及未触发，统一去重和本金 |

参考候选的原始来源： [Conformal Risk Control, ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/f3549ef9b5ff520a7e41ff3cc306ab2b-Abstract-Conference.html) 研究满足条件的损失风险控制，不保证每只股票安全；[DoubleAdapt 作者实现](https://github.com/SJTU-DMTai/DoubleAdapt) 明确提示 horizon/step 约束，不能直接当作 20 日反馈的每日适应方案；[MASTER](https://arxiv.org/abs/2312.15235) 支持研究市场引导关系建模，不证明本项目安全盈利。本次核查这些来源，不声称完成五年系统综述或调用了 mylib。

### 两条研究产品线，不偷换目标

- O：用户认可的安全 +15%/+20% 触达，后来回落不取消已经满足的机会成功；先行风险、触达后风险分别记录。旧 S20 的机会分加风险层仍是首要竞争者。
- P：固定期限扣费盈利及全窗口风险，直接安全盈利概率、联合四类、条件三头竞争。P 的 A/B/C/D 必须加 track 前缀，避免与旧 O 标签混名。
- T：O/P 预测固定以后，独立研究是否能够兑现；绝不使用事后最高价作为成交。

保留一个反共识分支：高机会、高波动股票不必永久排除，可比较冻结的预设止盈与固定到期退出。它必须在同候选、同本金、T+1、跳空、无法退出和 OHLC 顺序不明的保守条件下成立。若只有理想成交盈利，否定 T 可用性，不重写 O 标签。延迟入场同理：当日重评分是新决策，原失败、等待、未触发、错过上涨都保留。

### 首轮排名与不可缺少的反证

1. 旧锚加学习风险是否胜过旧锚加 ATR/流动性？在相同日期、相同 k、相近波动与流动性下检验，防止把低波动筛选包装为新的个股预测能力。
2. 直接安全事件概率是否已足够？联合四类/条件多头只有在跨折增量存在时继续；条件样本不足就停止，不用更多头掩盖问题。
3. 惩罚和硬门槛是否改善风险—盈利—覆盖前沿？同时报告净收益金额；不能以大量微利掩盖少数深亏，也不能奖励安全但小亏的股票。
4. 阈值残差集中才启动多阈值/分位数；顺序残差集中才启动危险率；持续漂移才启动成熟反馈滚动更新。
5. 序列/图/检索/表格基础模型/路径生成保留在路线库，不是必须训练的清单。无激活证据即带理由跳过。
