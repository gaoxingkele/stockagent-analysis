# Pool A R20 Target v1（冻结契约）

冻结日期：2026-08-30（Asia/Shanghai）
机器契约：`config/pool_a_r20_target_v1.json`

## 正式规则

池 A 只覆盖沪深市场，北交所继续由池 G 独立筛选。ST 在因子加载源头排除。

一只股票进入池 A，当且仅当：

```text
(预测第20日收盘收益率 >= +25%
 OR 预测未来20日内最高涨幅 >= +25%)
AND 预测未来20日最大不利幅度 >= -15%
```

`-15%` 的方向必须正确理解：`-10%` 比 `-15%` 更安全，因此通过条件是 `>= -15%`。

本版本不区分超跌反弹或趋势，不使用 V7c 速度/F1/F2/僵尸/行业动量作为池 A 准入条件；不设行业上限；不设 TopN。展示顺序按两种收益预测的较大值降序，再按 `ratio` 降序。排序不改变入池资格。

## 防未来数据约束

线上运行不能读取未来价格。`+25%` 和 `-15%` 是历史标签训练出的模型预测阈值，不是用未来真实收益直接过滤，也不是收益保证：

- `r20_pred`：预测第20个交易日的收盘收益率（百分比）。
- `pred_max_gain_20`：预测未来20个交易日内最高价相对入场价的涨幅（百分比）。
- `pred_max_dd_20`：预测未来20个交易日内最低价相对入场价的最大不利幅度（百分比）。

## 冻结边界

以下任一变化都必须创建新版本（例如 v2），不得静默修改 v1：

- `25 / 25 / -15` 任一阈值；
- 两条收益路径的 OR 关系或风险条件的 AND 关系；
- 模型文件或模型指纹；
- 沪深/北交所市场边界；
- 新增行业 cap、TopN 或其他硬过滤；
- 排序主键。

模型文件位于被 `.gitignore` 排除的 `output/`，其 SHA-256 已固化在机器契约中，用于部署机核验模型身份。

## 每日运行

Windows 计划任务 `StockAgent-DailyPools-2100` 每天 21:00 调用：

```powershell
powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File scripts/run_daily_pools.ps1
```

流水线先更新/验收外部池 E/F，再运行本项目全市场评分并原子生成 A–G 看板产物。无新交易日时保留最近成功信号日。
